# Своя переписка в поддержке с первого нажатия

Вошедший пользователь с подтверждённой почтой открывает персональный чат
одной кнопкой. Clipmkr переиспользует Libredesk v2.9.0 для показа последнего
диалога и сохранения истории между браузерными сеансами. Переписка остаётся
у текущего оператора. Выпуск зависит от согласования точного макета.
