# Тестовый checkout одного аккаунта

Владелец запросил доступ только согласованному аккаунту и отклонил глобальное включение.
Дельта ограничивает существующий checkout server identity и TEST-режимом; новые роли,
таблицы, провайдеры и дизайн не вводятся. Исполнение, ADR, план и QE ведутся в
`features/per-account-test-checkout/`; этот ledger хранит пользовательский контракт.
