# Уведомления поддержки в Telegram

## Причина
Сотрудник узнаёт о каждом входящем сообщении Clipmkr и отвечает в действующем Libredesk.

## Изменения
- Добавить приватный приёмник штатного вебхука Libredesk с доставкой через существующий бот.
- Ограничить данные в уведомлении кратким текстом и ссылкой на диалог.

## Возможности
- `support-telegram` — уведомления об обращениях.

## Влияние
Docker Compose, настройки Libredesk, существующий закрытый профиль Telegram.
