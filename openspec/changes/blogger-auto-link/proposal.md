# Автоматическая личная ссылка блогера

Владелец уточнил: блогер получает готовый адрес и отправляет подписчикам, без
самостоятельного придумывания кода. Сейчас PartnerPanel требует ручной код.

Личная ссылка назначенного блогера появляется автоматически рядом с проектами.
Сохраняются прежние коды, принадлежность, статистика и блокировки. Обычные пользователи
не получают автоматический код из-за монтирования компонента.

Статус: проект требований и автономный макет. Согласование, продуктовая реализация,
K1/K2, развёртывание и приёмка не выполнены. Авторитетные артефакты исполнения —
`features/blogger-auto-link/`; этот change хранит дельту требований.
