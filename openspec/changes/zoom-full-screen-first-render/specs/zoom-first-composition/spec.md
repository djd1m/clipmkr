## ADDED Requirements

### Requirement: Первая компоновка подтверждённой демонстрации

Первая вертикальная версия записи в подтверждённом режиме демонстрации
MUST сохранить все видимые границы записанного экрана с его пропорциями.

#### Scenario: Экран и камера присутствуют

- **WHEN** запись экрана с камерой впервые нарезается в подтверждённом режиме
- **THEN** зритель видит демонстрацию целиком и живую камеру одновременно
- **AND** отдельная камера находится за пределами области демонстрации

#### Scenario: Отдельная область камеры недостоверна

- **WHEN** приложение не может надёжно выделить отдельную область камеры
- **THEN** видео сохраняет весь записанный исходный кадр
- **AND** в кадре остаются уже записанные элементы

#### Scenario: Обычная разговорная запись

- **WHEN** режим демонстрации не выбран для обычной разговорной записи
- **THEN** первая нарезка следует существующему сценарию

#### Scenario: Повтор первой сборки

- **WHEN** первая сборка с выбранным режимом прерывается и возобновляется
- **THEN** повтор сохраняет целевую компоновку и однократное списание за запись

#### Scenario: Автоматическая компоновка нового клипа

- **WHEN** в новом горизонтальном клипе несколько кадров подтверждают демонстрацию с окном камеры
- **THEN** первая нарезка использует раскладку 02 без дополнительных действий при загрузке
- **AND** камера переносится при устойчивых подтверждённых границах на всех сохранённых отрезках
- **AND** при неустойчивом окне сохраняется полный исходный кадр с камерой на исходном месте

#### Scenario: Файл успел записаться до прерывания первой публикации

- **WHEN** повторяется рендер с уже зафиксированным автоматическим решением
- **THEN** повтор использует то же решение для неизменяемого объекта S3
- **AND** первые версии, начатые до включения автоматики, сохраняют прежнее кадрирование

### Requirement: Перенесённая камера видна один раз

При первой нарезке и ручной пересборке предпросмотр и итоговый MP4
MUST показывать переносимую камеру один раз. В слое демонстрации
MUST сохраняться видимое содержимое за пределами подтверждённого окна камеры.

Ручная пересборка MUST требовать подтверждение автора, что камера остаётся
в выделенном прямоугольнике весь сохраняемый фрагмент. Детектор лица
проверяет присутствие лица в области, границы фиксированного окна проверяет автор.

#### Scenario: Камера находится рядом с демонстрацией

- **WHEN** камера за пределами подтверждённой области демонстрации и переносится в отдельное окно
- **THEN** слой демонстрации содержит только область демонстрации, а камера показывается в отдельном окне

#### Scenario: Камера наложена на демонстрацию в исходнике

- **WHEN** подтверждённое окно камеры перекрывает демонстрацию и переносится в новое место
- **THEN** исходное окно исключается из слоя демонстрации
- **AND** видимый контент вокруг окна сохраняется
- **AND** содержимое, закрытое камерой при записи, не дорисовывается

#### Scenario: Положение камеры не подтверждено

- **WHEN** границы окна камеры недостоверны для показываемого фрагмента
- **THEN** остаётся исходная композиция без скрытия области и добавления второго окна

#### Scenario: Автор видит перемещение окна

- **WHEN** автор не может подтвердить неподвижность выделенного окна в ручной пересборке
- **THEN** запрос с переносом не отправляется
- **AND** автор может собрать клип с отключённым переносом камеры
