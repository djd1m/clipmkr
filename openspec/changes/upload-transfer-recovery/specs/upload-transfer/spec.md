# MODIFIED Requirements

## Requirement: Восстановимая передача

Система MUST различать неполную передачу файла и серверную обработку. Обновление списка
MUST NOT создавать ссылку просмотра uploading-записи. При уходе из активной формы по
ссылке текущей вкладки пользователь MUST подтвердить остановку; возврат MUST объяснять
повторный выбор того же файла и переиспользовать существующий multipart.

### Scenario: Обновился список во время PUT

GIVEN файл передаётся и запись uploading появилась после refresh
WHEN пользователь просматривает список
THEN карточка не предлагает перейти к просмотру и отменить передачу.

### Scenario: Запись открыта до завершения передачи

GIVEN статус uploading
WHEN открыта страница записи, в том числе спустя пять минут
THEN виден факт незавершённой передачи и путь к форме восстановления,
AND нет утверждения о продолжающейся серверной обработке.

### Scenario: Возвращение в исходную вкладку

GIVEN sessionStorage сохраняет исходный ключ и часть multipart уже принята S3
WHEN пользователь выбирает тот же исходный файл в форме
THEN используется прежний ключ/ID и отправляются только отсутствующие части.
