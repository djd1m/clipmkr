# Исключить преждевременный переход из загрузки

Появившаяся до первого PUT ссылка на запись может прервать передачу файла. После этого карточка
ожидает завершения загрузки, а восстановление зависит от состояния прежней вкладки.

Предлагается оставить идентификатор обычным текстом в форме и сохранить существующий
автоматический переход после успешного завершения. Исполнение, решения и проверки ведутся
в `features/prevent-upload-navigation/`; этот change хранит только дельту требований.

Статус: предложено, не реализовано и не принято.
