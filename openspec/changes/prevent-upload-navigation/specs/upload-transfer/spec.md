## ADDED Requirements

### Requirement: Форма сохраняет передачу до подтверждённого завершения

Форма MUST показывать идентификатор созданной записи без действия перехода к её карточке,
пока передача не завершена. Существующий автоматический переход MUST происходить после
успешного ответа завершения загрузки. Поведение паузы, ошибки и повторной передачи с прежним
ключом MUST сохраняться.

#### Scenario: Незавершённая передача

- **GIVEN** браузер получил запись и ссылки на части, а один из PUT ещё не завершён
- **WHEN** пользователь видит идентификатор записи в форме
- **THEN** идентификатор не является ссылкой или другим действием перехода
- **AND** запрос завершения не отправлен до подтверждения всех частей

#### Scenario: Успешное завершение

- **GIVEN** все части подтверждены хранилищем
- **WHEN** существующий запрос завершения успешно возвращает идентификатор записи
- **THEN** интерфейс автоматически переходит к этой записи
- **AND** завершение не вызывается повторно

#### Scenario: Ошибка завершения

- **GIVEN** файл передаётся через существующую форму
- **WHEN** передача или завершение возвращает ошибку
- **THEN** форма показывает предусмотренную ошибку и сохраняет существующие данные восстановления
- **AND** автоматический переход не происходит
