# Привести три пункта оферты к разовой покупке

## Why
При отсутствии автоплатежей §6.3/7.7/7.8 обещают их. Владелец поручил точечную обратимую замену.

## What Changes
Три абзаца описывают разовые покупки; старый текст сохраняется в old/new и отдельном обратимом коммите. Остальные условия, дата, интерфейс и платёжный backend прежние.

## Capabilities
### New Capabilities
- `one-time-offer`: точное соответствие трёх пунктов действующей разовой покупке.
### Modified Capabilities
Нет.

## Impact
legal-documents.ts и существующий approved-replacements.json. Новых зависимостей и API нет. Исполнение/проверки — features/one-time-offer.
