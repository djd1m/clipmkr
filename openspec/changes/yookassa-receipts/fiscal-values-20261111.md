# Подтверждение фискальных значений владельцем — 11.11.2026

Источник: ответ владельца «без ндс, услуга, полный расчёт». Дополнение: проверить, что публичное соглашение описывает услуги, а не продажу лицензии или права доступа.

Выбранные значения существующей конфигурации:

```dotenv
YOOKASSA_RECEIPT_VAT_CODE=1
YOOKASSA_RECEIPT_PAYMENT_SUBJECT=service
YOOKASSA_RECEIPT_PAYMENT_MODE=full_payment
```

Соответствие сверено с [официальным справочником ЮKassa](https://yookassa.ru/developers/payment-acceptance/receipts/54fz/yoomoney/parameters-values): код1 — без НДС, service — услуга, full_payment — полный расчёт. Код2 означает ставку0% и здесь не используется.

Это выбор ранее реализованных параметров, без новой бизнеслогики, нового значения по умолчанию или изменения schema/API. Значения записаны только в закрытый payments-live.env. Runtime по-прежнему использует TEST-магазин; факт выбора параметров не является выполнением боевого запуска или приёмкой настоящего чека.

Исполнение и границы: features/yookassa-receipts/11_fiscal_confirmation.md. Исторические proposal/design/spec pins не переписываются задним числом. Неподтверждённые ранее значения за10.11 не выдаются за исторически согласованные.
