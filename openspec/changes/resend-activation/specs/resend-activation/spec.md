## ADDED Requirements

### Requirement: Отправка существующим адаптером Resend
Система SHALL использовать существующий Resend transport для писем восстановления при валидном закрытом профиле и подтверждённом домене.

#### Scenario: Настройки отсутствуют
- **WHEN** API key или verified sender ещё не предоставлены
- **THEN** работающая почтовая конфигурация не изменяется и готовность доставки не объявляется

#### Scenario: Проверенный профиль подключён
- **WHEN** валидный профиль применён к web тестового clipmkr.ru
- **THEN** существующая форма восстановления доступна и разрешённый получатель может получить письмо через Resend

### Requirement: Сохранность и честная приёмка
Система SHALL сохранять код, данные и настройки вне трёх почтовых переменных; принятие письма provider не SHALL объявляться доказанной доставкой и сменой пароля.

#### Scenario: Тестовый web обновлён
- **WHEN** изменён почтовый профиль
- **THEN** Cloud.ru, остальные контейнеры и данные сохраняются, а действительный статус E2E указан отдельно
