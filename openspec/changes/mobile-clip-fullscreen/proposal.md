# Мобильный просмотр клипа на весь экран

Показать действие «На весь экран» у доступного клипа в кабинете и в гостевом
пакете с уже доступным плеером. Воспользоваться нативными возможностями каждого
браузера, сохранить позицию видео. Для ограниченной платформы предусмотреть
полноразмерный просмотр внутри страницы.
