## ADDED Requirements

### Requirement: Сохранность переноса
Перенос MUST сохранять все аккаунты, права, финансовую историю, рефералов, записи, клипы, ссылки и обращения/вложения поддержки без объединения аккаунтов и повторных начислений.

#### Scenario: Восстановленный срез
- **WHEN** восстановлена согласованная резервная копия
- **THEN** схема, строки всех таблиц и согласованные агрегаты совпадают; исходная и локальная базы сохранены отдельно

### Requirement: Единственный писатель
В каждый момент MUST существовать только один действующий комплект писателей перенесённого экземпляра, включая фоновые задачи и webhook.

#### Scenario: DNS-кеш старого адреса
- **WHEN** клиент обращается к прежнему IP после переключения
- **THEN** запрос обрабатывает новый экземпляр через relay либо пользователь видит согласованное обслуживание; старая база не принимает независимые записи

### Requirement: Проверки до переключения
Перенос MUST пройти проверку входа, загрузки, нарезки, просмотра, скачивания, почты, трёх ролей и TEST-платежей до ручного согласования DNS.

#### Scenario: Непройденная проверка
- **WHEN** тест не выполнен или не прошёл
- **THEN** результат остаётся открытым, DNS не переключается и реальные списания не включаются

### Requirement: Откат без потери новых записей
Откат MUST сохранять всю принятую после переключения историю.

#### Scenario: На новом сервере появились записи
- **WHEN** требуется вернуть старый сервер после новых регистраций, заданий или webhook
- **THEN** writers останавливаются и переносится актуальное состояние либо сохраняется единственная актуальная БД; возврат старого snapshot запрещён
