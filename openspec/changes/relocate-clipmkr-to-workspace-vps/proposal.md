# Зачем
Разместить действующий clipmkr.ru на рабочем VPS77.83.87.178, сохранив пользователей и данные с194.85.249.105.

# Что меняется
Физическое размещение приложения и его хранилищ, переходный маршрут и эксплуатационный runbook. Домен остаётся clipmkr.ru; DNS меняется только после отдельного согласования. Production поведение и реальные списания не изменяются. Для ранее принятого503 QA TEST контракта вводится только изолированный QA callback guard и отдельный QA web image; source/worker images остаются прежними.

# Влияние
Аккаунты, сессии, PostgreSQL, Redis/BullMQ, S3, почта, TEST webhook и поддержка. Авторитетный план и QE: features/relocate-clipmkr-to-workspace-vps/. Существующие данные stage и c.clipmkr.ru не объединяются и не перезаписываются.
