# Зачем

Владелец 25 ноября 2026 года запросил интерактивный сайт о добавленных возможностях Clipmkr за 18–25 ноября включительно по образцу отчёта от 18 ноября.

# Что меняется

Появляются автономный HTML, канонические данные, текстовая версия, реестр доказательств и воспроизводимый сборщик в `docs/reports/2026-11-25-project-dynamics/`. Публикация — отдельный каталог GitHub Pages `2026-11-18-25/` с сохранением прежних материалов.

# Влияние

Требования относятся к учебному отчёту. Контракты приложения, БД, медиаданные, домен Clipmkr и платёжные настройки не изменяются. План исполнения и QE хранятся в `features/project-dynamics-report-20261125/`.
