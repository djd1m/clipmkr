## Why

Обозначить условия использования исходного кода Clipmkr и сохранить отдельные уведомления поставщиков при распространении Git и образов.

## What Changes

- Указать в README границы Elastic License 2.0 для принадлежащего правообладателю кода и происхождение заимствований.
- Добавить официальный текст ELv2 и уведомление MIT, поставляемое рядом с весами YuNet.
- Отразить самостоятельные условия компонентов, медиа и платного сервиса.

## Capabilities

- `source-license` — сведения о правах в Git и сопровождение модели в образе worker.

## Impact

Документация репозитория и один текстовый файл в существующей директории assets worker. Условия фактической передачи каждого контейнерного образа проверяются по его содержимому.
