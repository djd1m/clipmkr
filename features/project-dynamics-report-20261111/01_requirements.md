# Требования к повторному отчёту

Основание: прямой запрос владельца 11 ноября 2026 года. Подготовка и дизайн
документа разрешены этим запросом; согласование нового UI приложения не требуется,
поскольку приложение не изменяется. Прежний образец и найденные исходные запросы
публикуются с точным указанием происхождения, без подмены восстановленным промптом.

- FR-1. Период 5–11 ноября 2026 года, только Clipmkr. Сравнить состояние прежнего
  отчёта с текущим: проблема → изменение → результат → граница доказательства.
- FR-2. Вынести исходный пользовательский промпт, его уточнения и параметры образца
  в Markdown. Новый воспроизводимый промпт явно отличать от исторического.
- FR-3. Каждый существенный факт и план имеют проверенный Git commit/path.
  Не путать опубликованное, SOURCE/QE, согласованный макет, исследование и бэклог;
  противоречивые или устаревшие документы разбирать явно. Нет общего процента
  готовности, выдуманных сроков, дохода, количества клиентов или метрик продуктивности.
- FR-4. Самостоятельный интерактивный HTML: поиск, совместные фильтры, хронология,
  раскрытие доказательств, следующие шаги, режим показа со стрелками/Escape,
  возврат фокуса и печать полного отчёта. Работает через file:// без сервера,
  CDN, npm и фоновых сетевых запросов, на ширинах 390/1440.
- FR-5. Видимый раздел «CJM и макеты» и соответствующий слайд: прямые ссылки
  на GitHub CJM, утверждённые HTML/PNG и актуальные требования. Исторические
  варианты и будущие макеты подписаны; приватные кадры не публикуются.
- FR-6. Все материалы на русском; публично нет email, паролей, токенов, customer IDs,
  приватных клипов, подписанных URL или закрытых конфигураций. Внешние ссылки
  открываются только по действию пользователя, с noopener/noreferrer.
- FR-7. Канонические данные совпадают со встроенными в HTML. Независимый reviewer
  другой модели сверяет ключевые факты и возможности документа на стабильных байтах.
  Проверка отчёта не называется повторной приёмкой приложения.
- FR-8. Опубликовать Markdown и HTML в GitHub, GitLab и GitVerse одинаковым SHA;
  дать ссылки на скачивание HTML и инструкцию открытия в Chrome.

Изменять продуктовый код, runtime, DNS, Cloud.ru, данные, оплату и роли запрещено
в рамках этого отчёта. Изучаются существующие Git/docs; будущие работы только описываются.
