# Ручная проверка упрощённого интерфейса

Статус: инструкция подготовлена, **новая версия ещё не опубликована**. Координатор укажет точную опубликованную ревизию и проверенные записи после поставки. Ниже ожидаемое поведение согласованного UI, а не заявление успешной приёмки. Проверяем на [clipmkr.ru](https://clipmkr.ru); перенос на Cloud.ru этой инструкцией не выполняется.

## Обычный пользователь

1. [Кабинет](https://clipmkr.ru/dashboard): выбрать исходный файл. До нажатия «Создать клипы» видны стоимость в кредитах и ограничение записи; сам выбор не начинает передачу. Вторичные настройки свёрнуты и доступны по раскрытию.
2. После явного старта видны передача файла и подтверждённый прогресс. Попытка уйти в аккаунт или статистику во время передачи запрашивает подтверждение; отмена сохраняет загрузку. Если передача прервалась, интерфейс объясняет, какой файл нужен для продолжения; начало обработки не объявляется до подтверждения сервера.
3. На странице записи выбрать готовый клип, нажать Play, дождаться движения счётчика и звука, скачать файл. Файл должен открываться в обычном проигрывателе. Готовые результаты при частичной ошибке остаются доступны; повтор обещается только там, где его разрешает сервер.
4. Через «Ещё» открыть нужное действие: поделиться или изменить оформление. Не требуется просматривать все вторичные параметры одновременно. Закрытие настроек или обновление стадии не сбрасывает проигрыватель и набранный текст. Музыка меняется только после явного применения; перед сохранением видны последствия пересборки.
5. Сохранить призыв и закрыть настройки: ожидание и итог сохранения остаются видны. При отказе показывается ошибка; неподтверждённый результат не выдаётся за успех.
6. [Аккаунт](https://clipmkr.ru/dashboard/account): проверить email, доступ, баланс и помощь. Переключить светлую/тёмную тему и «Кабинет»/«Монтажную», обновить страницу — выбор сохраняется. Удаление спрятано в отдельное раскрытие; **нажимать удаление для проверки не нужно**. Перед необратимым действием требуются отдельное подтверждение и видимые последствия.
7. [Пакеты](https://clipmkr.ru/upgrade): условия и причина недоступности покупки видны рядом с действием. В текущем согласованном тестовом окне покупка разрешена только выбранному владельцем аккаунту; глобальная продажа выключена. Настоящие списания этим выпуском не включаются. Исполнитель отдельно подтвердит успешный TEST-платёж и начисление.

## Блогер

1. После входа в [кабинет](https://clipmkr.ru/dashboard) личная автоматически созданная ссылка доступна без придумывания кода. Скопировать её; если браузер запрещает clipboard, воспользоваться видимым полем для ручного копирования.
2. Открыть [статистику](https://clipmkr.ru/dashboard/partner): это самостоятельный экран с возвратом в кабинет. Личная ссылка сохраняется при фильтрации; цифры подписаны как показатели за всё время. Заблокированная личная ссылка не предлагается для распространения.
3. Загрузка и получение клипа работают тем же путём. Максимальная длительность —120 минут по умолчанию либо индивидуальный лимит владельца; этот предел не равен числу доступных кредитов.
4. При смене аккаунта старые личная ссылка, цифры и локальные подтверждения не должны оставаться у нового пользователя.

## Владелец

1. В [управлении блогерами](https://clipmkr.ru/dashboard/bloggers) доступны поиск, назначение и причина изменения. Индивидуальные лимит и доля находятся во вторичных настройках; пустое значение сохраняет значение по умолчанию, неверное раскрывает нужное поле и не отправляется.
2. Отчёт открывается отдельно от формы назначения; возврат сохраняет незавершённую форму. Видны основные показатели и выбранный месяц. Предварительный расчёт вознаграждения не означает автоматическую выплату.
3. Обычный пользователь не получает инструменты владельца по прямой ссылке.

## Что прислать при расхождении

Адрес страницы, роль, действие и фактический результат; браузер и устройство. Пароли, cookie и подписанные ссылки хранилища в сообщение или Git не добавлять. Ручная приёмка владельца дополняет автоматические проверки. Публикация той же версии на c.clipmkr.ru и перенос данных выполняются отдельным последующим блоком после этой приёмки.
