# Решения по каждому семейству экранов

Статус: предложение для согласования, не реализованный интерфейс. Подробная
классификация каждого control с source:line — в audits/regular.md,
audits/blogger.md и audits/owner.md. Здесь общий порядок без дублирования матриц.

| Экран / состояние | Кому | Оставить по умолчанию | Раскрывать по запросу / переносить |
|---|---|---|---|
| Главная, регистрация / вход | Всем | Ясный выбор входа, поля текущей формы и одно действие отправки | Юридические подробности — ссылки; вторичные функции продукта не превращать в выбор перед входом |
| Восстановление пароля | Всем | Почта/новый пароль по текущему шагу, отправка, результат и возвращение ко входу | Диагностику/объяснения — по контексту; не скрывать ошибку или нужное действие |
| Подтверждение почты | Вошедшим | Состояние подтверждения и нужное действие | Общую справку — отдельно, не повторять призыв на каждом рабочем экране |
| Новая запись | Всем | Файл, применимый лимит, краткий баланс/расход и запуск | Музыка, заголовок, удаление пауз, CTA — закрытые дополнительные настройки с сохранением значений |
| Передача / проверка файла | Всем | Реальная стадия/прогресс, отмена/пауза по действующему контракту, понятная ошибка | Редакторские опции не конкурируют с передачей; навигационный guard остаётся |
| Прерванная передача | Всем | Выбор того же файла и действительное действие продолжения | Технические причины/детали — по запросу; нельзя прятать восстановление или обещать отсутствующую кнопку |
| Список записей | Всем | Название, состояние и переход к конкретной записи | Вторичные действия с записью — контекстно; дубли тарифов/большую панель лимитов убрать из потока |
| Расшифровка / выбор / монтаж | Всем | Текущая стадия и доступный готовый результат | Техническую подробность — по запросу; не предлагать все настройки клипа во время ожидания |
| Полная ошибка | Владельцу записи | Понятная причина и доступное восстановление | Подробности диагностики — отдельно; retry только при реальном серверном допуске |
| Частичный результат | Владельцу записи | Готовый player/скачивание, короткое сообщение и повтор только неготового | Редактирование/музыку/оценки — по запросу; не повторять запуск/списание за исходник |
| Готовые клипы | Владельцу записи | Выбранный player, выбор другого клипа, скачивание | «Ещё»: поделиться/оформление/оценки; не выносить все редакторские действия отдельными основными кнопками |
| Поделиться / гостевой пакет | По действующему праву | После явного действия — нужные поля и обязательное согласие перед отправкой | Сложные условия/сроки по контексту; согласие нельзя скрывать в advanced |
| Публичная короткая ссылка | Всем | Существующее превью и следующий шаг | Не изображать /c/ как уже существующий публичный video player или download |
| Кабинет блогера | Блогеру | Общий сценарий клипов плюс готовая личная ссылка и копирование | Ручные коды/кампании — дополнительно, статистика по явному входу |
| Статистика блогера | Блогеру | Имеющаяся сводка за всё время и принадлежность ссылки | Детали статусов/источников и выбор ссылки при нескольких — дополнительно; не придумывать monthly reward API |
| Назначение блогера | Владельцу | Поиск аккаунта, действие назначения, обязательная причина и сохранение | Индивидуальный лимит и nullable ставка — дополнительные параметры, закрытие не сбрасывает их |
| Отчёт владельца | Владельцу | Период и краткий итог, список блогеров | Детали ссылок/расчёта — по конкретному блогеру; правило20/30% не превращать в автоматические выплаты |
| Пакеты / переход к оплате | Всем по доступу | Полная цена, объём, срок и явное подтверждение; недоступность при отключённой оплате | Историю/развёрнутые объяснения — отдельно; финансовые последствия не advanced |
| Возврат после оплаты | Владельцу намерения | Подтверждённое/ожидаемое/ошибочное состояние и нужный следующий шаг | Технические данные — по запросу; успешный redirect не равен начислению |
| Аккаунт / настройки | Всем | Один обнаружимый вход, текущая тема и компоновка | Опасные действия — отдельный раздел с последствиями/подтверждением, без дублирования на рабочей странице |
| Поддержка и её служебные страницы | По фактическому доступу | Нужная пользователю помощь; служебная обработка только support operator | Owner unlimited не даёт автоматически supportOperator; это не четвёртая выдаваемая всем роль |

## Общие правила

1. Сначала убрать дубли точек входа и конкурирующие действия. Уже закрытые
   details не описывать как открытые на первом экране.
2. Дополнительное — не потерянное: сохранить параметры и давать краткое резюме
   действующих отличий. Открытие/закрытие не меняет цену, кредиты, роль или параметры.
3. Условно необходимое не становится вторичным: ошибка, продолжение загрузки,
   retry, платёжное подтверждение и согласие видимы именно тогда, когда нужны.
4. Основная зона готового результата — просмотр и скачивание; необязательная
   редактура не должна отодвигать player вниз за набор кнопок.

## Покрытие и ограничения

Обычный кабинет и ряд существующих состояний просмотрены через живой UI в
контролируемом обычном QA-аккаунте. Для блогера/владельца нет подтверждённых
подходящих QA-профилей на текущем сайте: их матрицы основаны на коде и согласованных
макетах, а не на выдуманном authenticated E2E. Роли ради исследования не повышались.
Новый самодостаточный HTML демонстрирует основные семейства; неизменяемые recovery/
legal/служебные экраны охвачены аудитом и не выдаются за полностью перерисованные.
