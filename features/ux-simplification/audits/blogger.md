# UX-аудит: блогер

Дата: 05.11.2026. Читающий аудит, без реализации. Рабочая копия: `ux-simplification`; согласованные требования: `features/ux-simplification/01_requirements.md`, обязательный CJM: `docs/acceptance/core-cjm.md`. Наличие текущего UI не означает его приёмку.

## Вывод и каркас для сводного макета

Блогеру нужны два заметных результата: **получить свои клипы** и **скопировать личную ссылку подписчикам**. Основной экран: файл → «Создать клипы», рядом компактная готовая ссылка + «Копировать ссылку», остаток кредитов и лимит файла, ниже последние записи и короткий результат привлечения. Ручной код, выбор источника/ссылки, расширенные счётчики и редакторские параметры не должны предварять эти задачи. Не добавлять тени, дополнительные виджеты и отдельную настройку роли.

Согласованный baseline автоссылки: revision `18e4fa98e72fd8bdc84287d6c7495b4e3410b907`, `docs/design/2026-11-05-blogger-auto-link.html` (другая рабочая копия `/tmp/clipmkr-blogger-auto-link-20261105`), строки 267–274. Готовая ссылка/copy, загрузка, ошибка с повтором и блокировка остаются видимыми. Создание автоматическое; старые ссылки/атрибуции сохраняются; блокировку нельзя обходить новой ссылкой. Это согласованный дизайн, **не реализованная возможность текущей ветки**. Копирование нельзя убирать в advanced. Новые предложения ниже требуют согласования сводного макета.

**Лимит и пробный объём — разные числа.** Обычный пользователь: предел файла 90 минут; блогер: 120 или индивидуальный owner override (`packages/shared/src/upload.ts:5–12`). Для credit-mode назначение блогера повышает lifetime-пробный бюджет до применимого предела, добавляя только разницу, без повторной выдачи уже потраченного (`packages/db/src/blogger-policy.ts:48–60`, `packages/db/src/credits.ts:22–41`). Поэтому 120 — не гарантированный текущий остаток каждого блогера; показываем фактический баланс и отдельный лимит. Исходный signup — 30 кредитов (`packages/shared/src/tariff.ts:13`); публичные 90 относятся к обычной роли. Нельзя обещать блогеру «пробный пакет 90», принудительно обрезать его файл до 90, или подменять кредитами серверный duration guard. Legacy-billing имеет собственные дневные квоты; новое оформление не мигрирует аккаунт.
