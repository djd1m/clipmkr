## Открытый платёжный блок

Тестовый alias уведомлений пока направлен в прежнюю тестовую копию, а checkout создаётся в основной. Для исправления есть отдельная feature-adr-фича [align-test-webhook-route](../align-test-webhook-route/01_requirements.md). Её служебный исполнитель не допущен независимым QE: после ошибки повторной проверки может сохраняться устаревший process-local допуск. Маршрут не применён, новые TEST-покупки в этой приёмке ещё не создавались, исторические платежи и начисления не менялись. Глобальная продажа и реальные списания выключены.

Третий цикл проверки этого отдельного блока ещё завершается. При достижении потолка с незакрытым условием дополнительный цикл требует отдельного согласования владельца на точную исправленную ревизию. Наличие UI, успешная сборка и автономное поручение не превращаются в успешный платёжный тест.

Короткая155-секундная запись не подтверждает пределы90/120 минут, полный WCAG, физический Chrome на Windows или завершение прочего бэклога. Финансовый helper с известной ошибкой общего FIFO остаётся исключённым из оснований приёмки; для одного обычного оплаченного задания подготовлен отдельный план сверки канонического SQL, который ещё не исполнялся.
