# Автоматическая компоновка на первой нарезке

Владелец поручил выполнить актуальный бэклог по порядку и начать с
автокомпоновки. Результат использует принятую раскладку 02 и существующий
пользовательский путь. Набор проверок ограничен новым сценарием и
потребителями результата.

- FR-1. Первая нарезка горизонтальной записи с устойчивым окном камеры
  поверх рабочего экрана автоматически показывает весь видимый экран и
  одну отдельную камеру по принятому макету 02. Дополнительного действия
  при загрузке нет.
- FR-2. Если есть свидетельства демонстрации, но границы камеры не
  подтверждены на всех замерах сохранённых отрезков, результат показывает
  весь исходный кадр без второго окна или маски. При отсутствии свидетельств
  демонстрации используется существующее автокадрирование. Это эвристика
  кадра с демонстрацией, приложение записи по MP4 не определяется.
- FR-3. Решение фиксируется атомарно до рендера. При повторе используется
  то же решение, даже если предыдущая попытка успела записать файл в S3.
  Текущие на момент выпуска клипы продолжают по прежним правилам.
  После публикации повтор/музыка/CTA используют
  сохранённое решение, ручная настройка имеет приоритет. Нового списания,
  задания или записи пользователя нет.
- FR-4. Принять результат на реальной записи владельца и синтетическом
  разговорном видео, сохранив звук, субтитры, монтажные отрезки и старые
  публикации. Проверить, что сохранённый снимок пересборки нельзя
  подменить автоматическим результатом.

Граница первой поставки — горизонтальная демонстрация с камерой,
прикреплённой к верхнему краю. Демонстрация без признаков камеры и видео
со сложными или перемещаемыми областями требуют последующего улучшения.
