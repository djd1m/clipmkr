# Независимая проверка проекта автокомпоновки

Три независимые сессии GPT‑6 Astra xhigh проверили качество компоновки,
риски выпуска и проверяемость требований. После уточнений `evaluate`
закрыл обсуждение без открытых замечаний. Digest состояния QCSD
`cfbb79950ee2d31e93b6126443c6c6436c81a8918d3290d9a455034098ace0f8`.

- Компоновка. Перенос разрешён только при одинаковом окне камеры на всех
  сохранённых замерах. Для подтверждённой демонстрации с неполным
  подтверждением окна остаётся полный кадр с камерой в исходной позиции.
- Риски. Решение должно переживать повтор после частичной записи в S3.
  Новый воркер получает уже проверенное решение; предыдущий останавливается
  до миграции. Откат учитывает также неопубликованные, отложенные и повторяемые
  попытки с выбранной автокомпоновкой.
- Проверяемость. Зафиксированы пороги, проверка исходного файлового
  контракта, повтор после потери ответа S3 и просмотр первой версии в браузере.
