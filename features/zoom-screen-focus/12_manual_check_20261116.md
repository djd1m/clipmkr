## Настоящий Zoom-пример в QA-кабинете

Войдите ранее переданной QA-учёткой. Здесь один20-секундный клип **«Zoom — пример03 „Фокус на действии“»**: экран с действиями и настоящая камера поверх него. Для проверки достаточно нажать Play, посмотреть весь клип и при желании «↓ Скачать». «Исходник» → «▷ Смотреть» показывает тот же фрагмент до оформления. Это отдельный импорт готового приёмочного медиа, а не новый проход загрузки/STT/выбора. Существующие записи пользователя сохранены. Полная визуальная приёмка владельцем не объявляется.

## Прежняя синтетическая запись — только техническая проверка

[Открыть запись с двумя готовыми клипами](https://clipmkr.ru/dashboard/videos/4cd17abc-4293-4ad1-bd2e-54500744b638).

**Ограничение примера, подтверждённое замечанием владельца:** эта запись подходит для технической проверки пересборки, но не для приёмки композиции «экран + наложенная камера». Фотография женщины уже встроена в синтетический исходник. В опубликованной версии3 выбран02, `camera=null`, `screen` занимает весь исходник: отдельного наложения камеры здесь нет. Переключение номера без выбора пригодных областей не доказывает желаемую композицию. Визуальная приёмка остаётся открытой; для неё нужен подготовленный пример «до/после» на настоящей Zoom-записи с явно видимым экраном и наложенной камерой.

Это синтетическая20-секундная запись в обычной QA-учётке. Логин и пароль переданы владельцу отдельно в закрытом файле, в Git их нет. Войдите этой учёткой на [странице входа](https://clipmkr.ru/#auth); для другой текущей учётки удобно отдельное окно инкогнито. По чужой учётке запись недоступна.

1. В строке **«Исходник»** нажмите **«▷ Смотреть»**. Проверьте воспроизведение и перемотку; **«↓ Скачать»** скачивает исходный файл. **«← К клипам»** возвращает к результатам.
2. Воспроизведите первый клип. Через **«Ещё» → «Изменить оформление» → «Экран + камера»** откройте варианты. По умолчанию выбран03, дополнительные области закрыты.
3. Переключите01/02/03 и нажимайте **«Смотреть весь фрагмент»**. Это предпросмотр; готовый клип меняется после отдельного подтверждения пересборки.
4. Если хотите применить другой вариант: **«Применить оформление»**, просмотрите весь фрагмент, отметьте подтверждение и нажмите **«Подтвердить пересборку»**. Используется одна операция суточной квоты пересборок; исходная запись повторно не оплачивается кредитами. До готовности новой версии можно смотреть старую.
5. После завершения проверьте Play и **«Скачать клип»**. Второй клип должен сохраниться.

## Что оценить на своей Zoom-записи

Откройте свою запись тем аккаунтом, который её загрузил. Проверьте, читаются ли действия на экране и не перекрывает ли их камера на всём фрагменте.03 увеличивает выбранную область действия; пока область не уточнена, сохраняется весь экран.01 показывает весь экран и камеру в свободной области,02 располагает экран сверху и камеру снизу. В **«Уточнить области»** можно поправить экран/камеру; отсутствие надёжной камеры показывается явно. Старые клипы не пересобираются автоматически при открытии страницы.
