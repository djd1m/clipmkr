## UX-04: принятая пересборка и локальный draft

ADR-003 теперь разделяет immutable submitted snapshot и последний editable draft с монотонной `draftVersion`. Accepted/pending, reload и failed не удаляют sessionStorage envelope. После reload и failed восстанавливается последний вариант для правки; повторного apply по одному факту reload не происходит. При неизвестном ответе сохраняется идентичность прежнего запроса.

Автоматическая очистка допускается при авторизованном подтверждении опубликованной версии, совпадении принятого request key/version, canonical config и source revision, а также совпадении непосредственно перечитанной локальной версии и layout с отправленным snapshot. Чтение и удаление описаны без async-разрыва. Поздние правки, включая A→B→A с новой draftVersion, сохраняются. Ограничения sessionStorage и явные исключения discard/смена аккаунта/истечение сохранены.

В ADR-003, AM-12 и OpenSpec заданы три различающих будущих browser oracle: accepted→reload→failed и продолжение редактирования; точная публикация очищает соответствующую запись; поздние правки и ABA переживают старую публикацию. Они описаны, но не выполнялись.

## Прежние условия и дельта

UX-01: scoped restore, предупреждение при отказе storage и честный предел SPA Back сохранены. UX-02: 03 без подтверждённого focus явно показывает whole-screen fallback, camera seed не становится action seed. UX-03: все три media по каждому play приостанавливают остальные; polling и смена clip не нарушают описанный lifecycle. Сверка R2 и R3 не выявила отмены этих условий.

Девять файлов ограниченного R2 архива совпали с его SHA; пять содержательных файлов (ADR-003, 04, 05, 06 и OpenSpec) изменены по узкому условию, три metadata/pins обновлены, source-pins прежний. Текущий host manifest из девяти SHA совпал; кумулятивный `changedScope` содержит 143 уникальных пути. Авторская оценка новых серьёзных рисков в этой дельте проверена; дополнительных условий в собственном UX scope не выявлено. Оценка касается изменений и их затронутых зависимостей, а не нового аудита неизменённой реализации.

Approved selector SHA-256 `76acda5003083138245031f5e96c6697e74844a8b5324e1007d397ac993eb1f0` не изменился. Новые состояния описаны как проект, не выданы за готовый согласованный UI.
