# Zoom: фокус на экранном действии и лицо

Владелец выбрал03 из `docs/research/zoom-screen-layout`. Прежнее кадрирование по лицу
может исключать демонстрацию экрана. Добавить явный режим screen+face:03 по умолчанию,
01/02 доступны в дополнительных настройках. Выбор — черновик до подтверждения.

Исполнение и gates принадлежат `features/zoom-screen-focus/`; этот ledger их не заменяет.
UI selector согласован владельцем11.11.2026 (свидетельство в feature ui-approval.md); реальное media и production не изменяются этим proposal.

Явное включение screen+face может однократно подготовить и сохранить camera seed в существующем worker/transport. Это анализ без пересборки/списания; повторные radio changes и preview не запускают render jobs. Нет новой ML-модели, очереди или сервиса.
