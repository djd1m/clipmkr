## Ограничения и завершение

Это положительная postrelease-проверка одного разрешённого исходника, не повтор всех predeploy состояний/ошибок. Postrelease WebKit, произвольные codecs, большой файл, 90–120 минут непрерывного просмотра, истечение подписи и принудительные сетевые сбои отдельно не прогонялись. Видимость controls и продвижение media time не равны субъективной проверке качества звука человеком.

Новые signup, upload, платежи, письма, S3 writes, DDL и чтение чужих originals не выполнялись. Прямой доступ к runtime DB не потребовался. В финальном запуске нет page errors; logout вернул 200, browser/context закрыты, временный скачанный файл удалён. Private evidence имеет права 700/600. Ограничение первой QA-сессии описано выше; её cookie не сохранялся, принудительная очистка других сессий не выполнялась.

Факт SOURCE closure, факты release backup/Env/image admission координатора и этот UI результат — отдельные доказательства. Этот отчёт не заменяет ручную приёмку владельца и не разрешает следующую Cloud/DNS-публикацию.

## Ручная проверка владельцем

1. Откройте [clipmkr.ru](https://clipmkr.ru/), выберите «Войти» и войдите в свой существующий аккаунт. Пароли в отчёте не публикуются.
2. В «Мои записи» откройте свою запись с доступной строкой «Исходник». Нажмите «Смотреть»: запись должна открыться без автоматического старта.
3. Запустите и остановите воспроизведение штатной кнопкой плеера. Нажмите «К клипам», затем снова «Смотреть»: выбранная карточка должна сохраниться, новое открытие — оставаться на паузе.
4. Нажмите «Скачать» именно в строке «Исходник». Дождитесь файла и откройте его локальным плеером.
5. Повторите открытие на узком окне/телефоне. Сообщите, устраивают ли расположение, читаемость и поведение. Доступность конкретного старого файла не обещается: при отсутствии исходника сайт должен показать соответствующее состояние.
