# Публичные планы Clipmkr

- FR-1. Посетителю без входа доступен публичный список. Из кабинета обычного
  пользователя, блогера или владельца к нему ведёт пункт «Планы Clipmkr».
- FR-2. «Предложить функцию» ведёт к существующему чату с пояснением.
  Подтверждённый пользователь может продолжить переписку и увидеть ответ.
  Гость видит вход/восстановление, неподтверждённый — подтверждение.
- FR-3. Публичный список ведётся из отдельного файла. Видны только
  вручную утверждённые обезличенные карточки. История Libredesk в
  публичной выдаче не запрашивается.
- FR-4. Статусы и карточки обновляются вручную через небольшой обычный
  коммит с проверкой содержимого. Публичная страница не обещает даты выпуска.
