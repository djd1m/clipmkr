## Ручная проверка владельцем

1. На https://clipmkr.ru/dashboard войти существующим аккаунтом назначенного блогера.
2. В карточке «Ваша ссылка для подписчиков» нажать «Копировать ссылку» и вставить в адресную строку отдельного окна инкогнито.
3. Обновить dashboard: ссылка должна сохраниться. Настройки → компоновка/тема должны сохранять готовую ссылку.
4. У обычного пользователя карточка личной ссылки блогера не появляется. Если старейшая ссылка заблокирована, автоматическая замена не создаётся.
