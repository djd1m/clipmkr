# Инвентаризация переиспользования

Исследовано чтением базы `e381a2a`; исполнение runtime не заявляется.

| Блок | Факт | Применение после согласования |
|---|---|---|
| `apps/web/src/server/partner-code.ts::ensurePartnerCode` | `randomBytes(9).toString('base64url')`, первый код по created_at/id, сериализация строкой partner | Основа стабильной ссылки; не новый генератор |
| `createOwnedPartnerCode` там же | Активный account lock, owned codes locks, запрет нового кода при блокировке | Сохранить инварианты автоматического пути и проверить конкурентными тестами |
| `apps/web/src/server/partner.ts::dashboard` | Принадлежность кодов, статистика и платежи | Переиспользовать, не терять дополнительные кампании/историю |
| `apps/web/src/app/dashboard/PartnerPanel.tsx` | Сейчас форма 6–12 символов | Убрать необходимость придумывать код для личного блока блогера |
| `apps/web/src/app/dashboard/page.tsx` | PartnerPanel смонтирован внутри закрытого details для всех | Открытый блок у проектов только для серверно подтверждённого блогера; обычным пользователям не mint на mount |
| `/dashboard/bloggers` | Назначение роли и лимитов | Не путать назначающего владельца и владельца referral identity |
| ThemeToggle, globals.css workspace токены, настройки компоновки | Согласованная нейтральная палитра/зелёный | Сохранить общий стиль и предпочтения |
| `docs/reuse/blogger-cabinet-projects-1-8.md` | Ранее исследованы проекты 1–8 | Приоритет действующим функциям Clipmkr; повторный перенос не нужен |

Новый OSS-пакет не нужен: генерация и хранение уже есть, clipboard — browser API,
макет — native HTML/CSS/JS. Поиск библиотек для готовой native функции не выполнялся.

Риски будущего кода: удаление аккаунта одновременно с mint, снятая роль, блокировка
другой кампании, повтор/параллельный первый запрос. Чтение SQL не доказывает эти
комбинации; потребуются тесты на настоящей PostgreSQL.
