# Требования смены музыки при частичном результате

Владелец поручил последовательно выполнить текущий бэклог. Этот пункт
переиспользует существующий контрол «Музыка» в оформлении клипа.

- FR-1. Готовый доступный клип можно переоформить при `rendering` и `done`
  родителя. Чужой, недоступный или уже пересобираемый клип отклоняется.
- FR-2. Для смены музыки применяется штатный лимит пересборки выбранного
  клипа. Кредиты записи не меняются. Повтор не создаёт вторую попытку.
- FR-3. Предыдущий готовый файл остаётся доступным до публикации нового.
  Соседние фрагменты продолжают обработку. Срок хранения действует.
