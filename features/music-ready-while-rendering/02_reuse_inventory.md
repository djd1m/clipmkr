# Переиспользование

- `ClipMusicChoice.tsx` уже показывает каталог для `clip.available`. UI
  не зависит от статуса записи. Нормальные условия хранения, квота,
  блокировка повторной задачи и смена версии находятся в `ClipMusicService`.
- `leaseAttemptTx` требует готовый клип при `rerender` и использует
  собственный fence клипа. Общая запись блокируется первой, как при
  первоначальном рендере. Соседний клип имеет свой fence.
- `lockRender` принимает готовый клип при `rerender` независимо от
  статуса записи. `publishRenderResult` меняет отдельный клип, оставляя
  прогресс родителя первоначальным попыткам. Рабочий прецедент проверки
  допуска при `rendering` есть в `clip-layout.ts`.
- У пользовательского примера текущая медиазапись готового клипа
  недоступна для новой проверки. Приёмка использует отдельный
  синтетический частичный результат.
