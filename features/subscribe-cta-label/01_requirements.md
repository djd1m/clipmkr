# Видимый адрес подписки на канал

Базовая ревизия `63a9f04cb366d12e8a05177240edd581836eb777`. Для `subscribe` действующий MP4 без метки получает «Подписывайтесь на автора». На публичной странице адрес уже является назначением кнопки, текст которой «Подписаться →». Владелец уточнил, что вместо общей фразы должен быть сам адрес канала.

- FR-1. Публичная кнопка подписки показывает и открывает сохранённый HTTPS-адрес. Домен назначения виден в текущей подписи, длинная строка переносится на узком экране.
- FR-2. Для короткой публичной HTTPS-ссылки без query и фрагмента, которая подходит для существующей области, новый MP4 показывает адрес в финале при наличии метки и без неё. Непригодный для кадра адрес доступен на публичной странице, в MP4 сохраняется прежний словарь.
- FR-3. Если отображаемый адрес меняется, используется штатная атомарная пересборка и её квота. Смена URL, которая не меняет надпись, не ставит задания. Старый файл доступен до успешной публикации нового.
- NFR-1. Воркеры не обращаются по адресу. FFmpeg читает допустимый адрес из временного текстового файла. Сырой адрес не попадает в журнал или ключ объекта. Остальные типы CTA, URL-валидация, CSP, порядок слоёв и прежний бюджет пересборок сохраняются.
