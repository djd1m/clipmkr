## Code/spec anti-drift

На странице показывается проверенный адрес выбранного призыва. В MP4 попадает только короткий подходящий адрес подписки. Query и fragment в кадр не передаются. При окончательном отказе пересборки публичная кнопка может уже показывать изменённую ссылку, а прежний MP4 остаётся доступен. Архив опубликованных MP4 обновляется только через успешную пересборку.

Native QE закрыл исправленный снимок `180ad42fe362162763d5edd375932a8d52ad3a1c11437ba725b07fade73503f6`. Повторно проверены все строки таблицы и единственный документальный diff.
