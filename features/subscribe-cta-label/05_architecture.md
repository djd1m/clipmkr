# Путь ссылки

Форма → существующее поле `video.cta_url` → публичная кнопка `/c/{code}`.
Ветка рендера передаёт в тему призыва только допустимый адрес подписки. FFmpeg получает фиксированный путь к временному текстовому файлу с правами 0600. Ссылка остаётся данными, вывод в публичном HTML экранируется, парсинг и чтение адреса не включают сеть.

Смена адреса сравнивает старое и новое отображаемые значения под текущей блокировкой записи. При различии тот же механизм меняет версии готовых клипов и выпускает задания одной транзакцией. До принятия новой версии прежний объект остаётся опубликован.
