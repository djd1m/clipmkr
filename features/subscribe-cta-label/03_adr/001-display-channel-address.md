# ADR-001 Показывать адрес подписки через существующий CTA

Статус: предложено для согласования.

## Контекст и критерии

Исторический ADR о призыве намеренно оставлял адрес в HTML. Для подписки владелец запросил сам адрес. Нужны читаемость, сохранение обоих путей публикации и отсутствие нового вычислительного или сетевого сервиса.

## Решение

В публичной кнопке подписки показать полный проверенный HTTPS-адрес. В рендер передаётся адрес только для подписки. Для надписи выбирается короткая публичная ASCII-ссылка с допустимым путём, без query и fragment, которая помещается при штатном минимальном кегле. Ссылка передаётся FFmpeg через временный текстовый файл по образцу заголовка. Непригодный адрес остаётся на веб-странице, прочие режимы сохраняют статический текст. Изменение строки в пикселях запускает прежнюю атомарную пересборку. В контракте хранилища используется хеш отображаемого значения.

Вариант с изменением только HTML проще, но оставляет прежнюю надпись в скачанном клипе. Вставка полного произвольного значения прямо в фильтр ухудшает изоляцию данных и не помещается на части видео.

## Последствия

Для применения нужны web и video worker. Миграции, новые зависимости и автоматическая пересборка архива не нужны. Готовый MP4 обновляется при следующей штатной пересборке.
