# Архитектура

Авторизация → один запрос Cloud.ru → текущая транзакция завершения и личного
возврата → существующий журнал воркера. Штатный повтор сохраняет id исходника
и транскрипт. Блокировки: аккаунт, видео, creditAccountLock и освобождение резерва, затем
личная строка квоты. Тот же порядок соблюдает штатный повтор другого видео. Старые callers
`failSelection` используют исходный контракт через необязательное расширение.
