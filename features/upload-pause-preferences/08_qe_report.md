  затронутых сценария, по 16 на Chromium и WebKit. В выбранном наборе пропусков нет.

  проверок интеграционного файла с PostgreSQL и Cloud.ru S3. Серверные исходники

- На снимке поставки прошли `npm run typecheck`, `npm run lint` и `git diff --check`.
  Проверка `npm run openspec -- validate upload-pause-preferences --strict --no-interactive`

## Проверка на clipmkr.ru

Выпуск подтверждён публичным `/health` 17.11.2026 в 20:48 UTC.
На тестовой учётной записи загружена синтетическая запись 28 400 810 байт.
Браузер отложил отправку частей 2 и 3 до паузы для воспроизводимости.
Часть 1 подтвердилась прямым PUT и повторным чтением списка частей S3.
В той же вкладке отключена настройка «Убрать паузы». На продолжении браузер
использовал тот же ключ, multipart и запись. S3 принял части 2 и 3.
Сервер принял один Complete с новым значением настройки и использовал один
дневной слот. Обработка завершилась расчётом одной записи на 159 секунд.

Playwright воспроизвёл созданный клип в кабинете. Скачанный MP4 совпал
с объектом S3 по SHA-256. `ffprobe` подтвердил вертикальное видео
длительностью 33,61 секунды. Проверка завершилась в 20:50 UTC.

Исторический файл SD-WAN по имени сервером не идентифицирован. Приёмка
на сайте выполнена на синтетической записи. Ручная проверка владельцем
в Chrome на Windows ожидается.
