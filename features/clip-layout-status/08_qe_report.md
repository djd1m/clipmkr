# Проверки компактного статуса пересборки

## Контракт и пользовательское поведение

| Требование | Фактическая проверка |
| --- | --- |
| FR-1, FR-4. Текущая попытка, закрытый редактор, отсутствие статуса у соседнего клипа | `npm run test -- tests/progress-screen.integration.test.ts` на отдельной PostgreSQL БД — 5/5 на начальной ревизии реализации. Клиентский путь дополнительно проверен настоящим Chromium. |
| FR-2, FR-3. Новая версия на четыре секунды, прежний файл при сбое, клавиатурное действие | `node node_modules/vitest/vitest.mjs run -c vitest.browser.config.ts tests/browser/clip-layout.test.ts -t 'composition status stays'` — начальный целевой сценарий 1/1. Остальные сценарии вне фильтра. |
| NFR-1. Плеер не сбрасывается при опросе и смене предпочтений | Отдельный Chromium-сценарий `chromium: second player survives` — 1/1. Первый запуск под параллельной нагрузкой завершился по тайм-ауту, целевой повтор прошёл. |
| Маркер актуальной работы | В отдельной копии удалено равенство серии. Тест PostgreSQL выявил ложный pending. Рабочие исходники не участвовали в мутации. |

Начальная проверка типов веб-приложения `npm run typecheck -w apps/web` — exit 0.
Первый запуск новых тестов выявил недостающую ссылку клипа в тестовой БД,
взаимное влияние тестовых записей и слишком короткий бюджет браузерного
сценария. Исправлены только тестовые данные и ожидания. Использовались
выделенный БД-сервис и штатный Playwright.

## Code/spec anti-drift

Статус носит только текущая попытка установленной версии и той же серии
раскладки. Адрес файла по-прежнему получает версию опубликованного MP4.
Другие типы пересборок сохраняют собственные сообщения, серверный лимит и
текущий запрос в очередь. Добавляется одно поле в существующий защищённый
список. Дополнительный таймер опроса и миграции не требуются.

## Независимое ревью

`gpt-6-astra xhigh`, отдельная сессия без истории реализации. Исходный
снимок `f2e4649744e34c3ad2f5d9b003678c5b9395a4fc0b3d2e73b9599de6feb9627f`
имел одно условие о контрасте действия при наведении. После локальной
CSS-правки снимок
`cd9afe4165d5b9bbe9882edd3a07328b378700f157c3944bb015ddcd5ab35546` закрыт
native evaluate. Контраст при наведении 10,90:1 и 6,87:1 в тёмной и
светлой теме в независимом пробнике. Его отрицательный контроль
воспроизвёл дефект без изменения исходников. На исправленном снимке
повторён целевой Chromium-сценарий 1/1 с проверкой обеих тем.
