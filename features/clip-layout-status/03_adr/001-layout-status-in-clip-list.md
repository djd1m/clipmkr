# ADR-001. Статус из существующего списка клипов

## Status
Принято для согласованного макета.

## Context
Редактор опрашивает подробности только пока раскрыт. Общая попытка пересборки видна в clip.list и включает музыку, CTA и раскладку.

## Decision
Вернуть необязательный статус актуальной пересборки раскладки вместе с существующим clip.list. Соединять актуальную попытку с намерением раскладки по клипу, версии и серии. Сохранить поля остальных потребителей. После подтверждённого POST обновить список существующим refreshRead. В карточке показывать процесс, подтверждённый сервером отказ и короткий успех при обнаруженной смене опубликованной версии. Историческая публикация на первом чтении служит базой.

## Consequences
Один защищённый запрос для карточек, без нового таймера опроса. Предпросмотр и другие виды пересборок не меняются. Дополнительный статус не содержит request key и параметров редактирования.
