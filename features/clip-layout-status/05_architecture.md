# Архитектура

Владелец записи → существующий SSR и clip.list → выборка clip, текущей попытки по fence и intent раскладки по clip_id, render_version и series_no → DTO → VideoDetail → ClipCard. Успех допустим только при совпадении версии опубликованного MP4 и текущей пересборки; ранее опубликованные версии и чужие типы не подтверждают успех.

Очередь и текущий рендер обозначены одним pending. В прочих случаях только актуальная ошибка или краткий успех. Кнопка ошибки возвращает в существующий контекст редактирования, закрытие панели возвращает клавиатурный фокус к видимому исходному элементу. Локальный черновик не подтверждает принятие задачи.

Использовать штатный refreshRead по успешному принятию, затем имеющийся опрос. Предыдущий плеер остаётся тем же элементом до фактической публикации.
