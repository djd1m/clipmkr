# Требования

Согласован [макет](../../docs/design/2026-11-18-clip-layout-status.md) из коммита `c5d3389d094a02c178de0f2e0fab89f3fc8d3942`. Ответ владельца «отличный макет - делай».

- FR-1. После принятой пересборки видна одна строка «Обновляем оформление…» под заголовком нужного клипа при закрытом либо открытом редакторе. Прежний доступный файл продолжает открываться и скачиваться. У соседнего клипа, изменения черновика, музыки и CTA отдельного статуса раскладки нет.
- FR-2. «Оформление обновлено» на короткое время (четыре секунды) появляется после обнаруженной публикации новой версии. При первом открытии карточки со старой завершённой пересборкой исторического уведомления нет.
- FR-3. При отказе последней актуальной пересборки раскладки видна строка «Не удалось обновить оформление» и действие «Открыть редактор». Оно открывает ту же панель оформления, доступно клавиатурой и не отправляет повтор.
- FR-4. Сворачивание, смена выбранного клипа и повторное открытие не отменяют пересборку. При повторном открытии текущая очередь/ошибка видны из серверного ответа. У отсутствующего или просроченного файла новая строка скрыта по обычной доступности клипа.
- NFR-1. Повторно использовать запросы, оформление и права доступа Clipmkr. Без миграций и зависимости от содержимого локального черновика. Смена версии файла, квота и технический статус продолжают работать по существующему контракту.
