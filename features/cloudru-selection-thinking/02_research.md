# Переиспользование и ограниченный выбор

apps/worker/src/llm/provider.ts (~73 строки) уже владеет одной request ветвью Cloud.ru/OpenRouter, endpoint/model/prompt, общим response parsing, provider-specific600000/240000ms deadline, cancel/error classification и transport disposal. Нужное изменение — один литерал внутри существующего cloudru body spread; новые helpers/export/config не нужны.
apps/worker/src/llm/cloudru-transport.ts остаётся действующим transport; prompts/selection.ts, packages/shared/src/fragments.ts validateFragments и worker selection pipeline не меняются. No duplicate provider path. Донора projects1–8/новой библиотеки нет оснований искать для дополнительного JSON field существующего клиента.
tests/cloudru-provider.test.ts уже захватывает настоящий сформированный request body через injected fetch и покрывает schema, malformed/null/truncated/refusal,429/503,network/redirect, caller abort и deadlines. Расширить этот seam положительным Cloud.ru и отрицательным OpenRouter assertions, не копировать provider implementation в test.
Альтернативы: vendor thinking.type=disabled отвергнут реальным probe; увеличение timeout/смена model/provider/новый token cap отвергнуты как лишнее изменение без требования. chat_template_kwargs.thinking=false — единственный выбранный параметр; enable_thinking тоже работал в отдельном probe, но не добавляется.
code-impl применён до плана: native reuse, ровно одна boundary правка, не ослаблять validator, различать mock test и реальную интеграцию. studio-extended-qe использует pinned contract-testing/risk-based-testing и локальные negative cases; AQE runtime не установлен. Высокий риск — поле уйдёт не тому provider или mock скроет реальную семантику; mitigations: capture обоих payloads и настоящий uncapped worker replay. Prompt/validator/token/timeouts не меняются, чтобы результат оставался причинно связан с одним полем.
