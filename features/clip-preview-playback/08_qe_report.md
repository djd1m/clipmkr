## Подтверждённое поведение

На прежнем опубликованном коде все четыре файла играют через программный play, HTTP206.
Это не проверяет пользовательский запуск. Отдельный опыт с указателем: нижняя кнопка
нативного плеера запускает клип; клик по центру при preload=none оставляет paused=true,
readyState=0. После разрешения metadata тот же клик запускает видео.
Проверенный файл: H.264 High4.1/yuv420p,1080×1920,25fps; AAC-LC,44,1кГц,stereo;36,24с.
При запуске нижней кнопкой декодировано93 кадра,0 dropped; время3,56с.
Windows User-Agent на Linux не является запуском Windows Chrome и не доказывает
сетевое окружение или работу GPU владельца.
