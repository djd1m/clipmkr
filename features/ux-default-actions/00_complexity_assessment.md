# UX-001. Сложность и границы

Уровень **M**, 9 баллов. База `5053cb84d157d3adb3f04dd4a1399bcb3e17f1b1`. Ожидаются четыре существующих TSX-компонента и адресные обновления двух существующих тестов. CSS допустим только при подтверждённой необходимости и включён в верхнюю оценку. Прототип, снимки и документы исключены из оценки продуктового диффа.

| Измерение | Балл | Основание |
| --- | ---: | --- |
| Продуктовые файлы и проверки | 2 | 4 компонента и 2 существующих теста, до 7 файлов с CSS |
| Области | 2 | Выпуск клипов и отчётность блогерского кабинета |
| Интеграции | 1 | Текущие UI и серверные проекции |
| Совместимость | 2 | Видимое размещение и текст меняются при сохранении API |
| Модель данных | 1 | Существующие поля и семантика |
| Сквозные области | 1 | Существующие границы и трассировка ошибок |

Этапы 0 → 1 → 3 → 3.5 → 5 → 6 → 7 → 8. В анализе подтверждены исходные состояния и потребители. Визуальный переход требует явного согласования макета и актуального checkpoint. Независимые QCSD, проверка плана, K1/K2 и QE сохраняются.

Ориентир для планирования после согласования: реализация 35–65 минут, адресная и независимая проверка 25–45 минут, подготовка поставки и E2E на тестовой копии 15–25 минут. Итого 75–135 минут активной работы. Время реальной обработки и окно ручной приёмки определяются стендом и владельцем. Это оценка без замера в этой сессии.
