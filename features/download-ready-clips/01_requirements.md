# Скачать все готовые клипы

Статус — черновик для согласования по [макету](../../docs/design/2026-11-25-download-ready-clips.html). Массовое скачивание — предложенный исполнителем способ сократить действия. Решение владельца по кандидату ожидается. OpenSpec-дельта появится после согласования. Основание — [аудит действий](../../docs/research/ux-default-actions/task-efficiency-20261125.md).

- **FR-1.** На странице записи перед плеером после сводки доступна одна вторичная кнопка «Скачать все готовые (N)», когда у записи минимум два доступных готовых клипа. При трёх из трёх подпись содержит 3, при двух из трёх — 2. При нуле или одном кнопки нет.
- **FR-2.** Одно нажатие запускает отдельные скачивания MP4 для каждого готового клипа этой записи, по текущему контракту карточки: сервер сообщает `available`, состояние хранения отличается от `expired`, известная дата `expires_at` ещё не наступила. Отсутствие даты или статус хранения `unknown` сами по себе не исключают доступный клип. Сервер файлового маршрута принимает окончательное решение по правам, состоянию и сроку хранения для каждого запроса. Действие использует авторизованный `startClipDownload`.
- **FR-3.** После нажатия показывается число запусков и подсказка про разрешение браузера на несколько скачиваний. Пользователь может вернуться к скачиванию отдельных клипов. Получение файлов зависит от браузера и ответов сервера.
- **FR-4.** У частичного результата сохраняются плеер, отдельное скачивание, помощь и действующие условия показа стоимости и повтора обработки. В показанном случае есть «Повторить» по `next_action=retry` и строка «2160 секунд · 36 кредитов. За эту запись — один раз.»

Объём согласования — кнопка кабинета. ZIP, новый файловый маршрут, перенос гостевого токена и изменения в выставлении стоимости находятся за границей этого предложения.
