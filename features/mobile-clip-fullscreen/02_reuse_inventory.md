# Переиспользование

- В `ClipCard.tsx` есть родной video с `controls`, `playsInline` и
  действующими ссылками на версию. `guest-page.ts` использует такой же
  элемент со штатным доступом по ссылке пакета.
- Действие пользователя открывает тот же элемент стандартным
  `requestFullscreen` или доступным нативным API iPhone. Поддержка
  зависит от контекста и браузера.
  [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen) ·
  [WebKit](https://webkit.org/blog/6784/).
- Если браузер отклоняет запрос, существующий плеер занимает доступную
  высоту окна через CSS. Проверить скрытие остального экрана, выход и
  возврат фокуса. Дополнительный плеер, копия файла или новая вкладка не нужны.
