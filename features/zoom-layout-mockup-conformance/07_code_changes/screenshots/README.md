# Реальный C1 UI на синтетических данных

Снимки сделаны браузером в приложении, а не в HTML-макете. Root просмотрел оба перед публикацией: тестовые цветовые поля, без пользовательского медиа, email, секретов или подписанных URL. Это проверка интерфейса до выпуска; состояние работающего сайта ими не объявляется обновлённым.

Весь родительский экран не объявляется пиксельно идентичным отдельному исследовательскому прототипу. Обе темы и390/1440 проверены также Chromium/WebKit — фактические границы в [C1](../c1.md).
