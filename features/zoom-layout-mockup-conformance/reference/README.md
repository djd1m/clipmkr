# Макеты перед реализацией исправления01/02

## Неподменяемый визуальный эталон

Эти два изображения получены из **неизменённого оригинального HTML11.11**; это не новые варианты дизайна. Публичная версия содержит заглушки вместо приватных кадров. Original commit `9e19f5746a28bad89c9551ce8cd9934f0f0a4f8e`; sourceSHA и SHA изображений — в [pins.json](pins.json).

- **[Оригинал01 — весь экран и камера справа поверх](original-01.png)**.
- **[Оригинал02 — камера справа сверху, рабочая область ниже](original-02.png)**.
- [Сам исходный HTML](https://github.com/djd1m/clipmkr/blob/9e19f5746a28bad89c9551ce8cd9934f0f0a4f8e/docs/research/zoom-screen-layout/mockup.html).

Размер снимков360×640. Рамка/объясняющие надписи исследования не становятся новыми обязательными титрами MP4. Приёмочные области/положения должны вычисляться независимо из оригинала; новый renderer не служит oracle для самого себя.

## Предлагаемые уточнения интерфейса — ещё не согласованы

[Интерактивный HTML](selector-v2-mockup.html): оболочка ранее согласованного selector с возвращёнными оригинальными01/02. HTML можно скачать через Download raw file и открыть локально. Никаких запросов к серверу, приватного медиа, рендеров или списаний здесь нет.

- [Экран01 на телефоне](selector-v2-01-390.png).
- [Экран02 на телефоне](selector-v2-02-390.png).
- **[Независимая высота области в дополнительных настройках](selector-v2-roi-390.png)** — нужна, чтобы выбрать работу другого соотношения сторон; ширина не должна незаметно сбрасывать высоту.
- **[Старый клип: явная кнопка перехода](selector-v2-old-390.png)** → [новое оформление только в черновике](selector-v2-upgrade-390.png). Само открытие не меняет старый published MP4, music/CTA тоже его не переводят.
- [Предложение02 с призывом](selector-v2-02-cta-390.png): заголовок слева сверху, две строки субтитров ниже screen, отдельная CTA-зона. Это визуальное предложение; точное уместившееся native fontbbox пока не доказано. До K2 нужен измеренный qualification; при неумещении — остановка и уточнение, а не скрытие контента.

В HTML доступны query-параметры `?edit=1&layout=01`/`02`, `&old=1`, `&areas=1`, `&cta=1`. Это ограниченный интерактивный макет: движущееся видео, настоящий media/durable draft/применение и межсессионное хранение он не доказывает. Подтверждение в макете не считается согласием владельца на код.

Проверены браузером390px: отсутствие горизонтального переполнения, ошибкиJS0, внешнихHTTP-запросов0; originalPNG360×640. Height/width/x сохраняются в пределах страницы, выбор target восстанавливает своюheight; upgrade переключает только модель отображения, без serverwrite. Проверка самого HTML не заменяет app/browser/native QE исправленного кода.
