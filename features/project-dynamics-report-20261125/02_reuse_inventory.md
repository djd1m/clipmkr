# Переиспользование

| Источник | Применение |
|---|---|
| `docs/reports/2026-11-18-project-dynamics/index.html` на базовой ревизии | Существующие типографика, палитра, структура страницы, фильтры, раскрытие карточек, слайды, клавиатура и печать |
| `docs/reports/2026-11-18-project-dynamics/render.mjs` | Сборка точных данных и безопасное экранирование автономной страницы |
| `docs/reports/2026-11-18-project-dynamics/data.json` | Схема v1 для событий, источников, уроков, плана и презентации |
| Браузерная проверка прошлого выпуска | Покрытие офлайн-загрузки, управления, печати и мобильного просмотра на установленном проектном Playwright |

Потребители — читатели страницы на GitHub Pages и пользователи скачанного HTML. Контракты — JSON v1, HTML-идентификаторы управляющих элементов и URL источников по полным SHA. Новые зависимости не требуются.
