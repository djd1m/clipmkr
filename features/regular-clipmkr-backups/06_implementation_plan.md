## Goal state

Сейчас регулярного охвата Clipmkr нет; две ручные свежие PG-копии не являются расписанием. Цель — один bounded почасовой native capture+encrypted snapshot+две verified immutable copies, с честным actual age и проверенным изолированным offsite восстановлением. Нет нового продукта backup, автоматического restore, schema/платёжных/UI изменений или заявленного cross-store атомарного RPO.
SPARC: specification —01/OpenSpec/ADR после фактического approval; pseudocode — lock → verify bindings/ownership → own orphan cleanup → sizing/free-space preflight → bounded fresh capture/JSONL prefix → validate → atomic publish/old-set cleanup → repo space recheck → restic backup → copy+verify primary → copy+verify secondary → success receipt; architecture —05; refinement — focused fault tests/native temp roundtrip; completion — independent QE и один current scheduled run/restore evidence.
Уровень coverage в процентах не выдумывается; цель — все named refusal properties и FR с действительными assertions. Новая логика не добавляется в существующие ≥700LOC release scripts.

## Риски и stop conditions

Foreign retention side effect → прямой native adapter; partial/stale snapshots → fresh run/atomicpublish; общие bindings/lock → actual identity + real flock; недоступный offsite → failure и last age; свободный диск/длительность → preflight и bounded timeout; невосстановимый ключ → честный DR blocker; shared Redis → no liveoverlay; online mismatch → workers closed/reconcile. Если нужен новый сервис/foreign infra patch/общий schema change — остановить boundedM и reroute.
