## Приглашение партнёров

Для знакомства и ограниченного пилота можно отправлять **https://clipmkr.ru**. Новый обычный аккаунт получает30пробных кредитов, то есть30минут исходной записи; лимит одной записи90минут не является бесплатным балансом90минут.

Для блогера-партнёра: он регистрируется своим email, владелец на [странице блогеров](https://clipmkr.ru/dashboard/bloggers) назначает роль/ставку/нужный лимит. Для нового credits_v1 аккаунта существующий canonical пробный бюджет повышается до лимита блогера (стандарт120минут), уже потраченные минуты не восстанавливаются. Legacy-аккаунты автоматически в новую credit policy не переводятся. Блогер получает автоматически создаваемую партнёрскую ссылку в своём кабинете и может распространять её.

Суммы партнёрского отчёта пока предварительные: в истории есть2успешных TEST-транзакции. Их точный закрытый перечень `/root/.config/clipmkr/live-activation-20261111/test-payments-exclude-from-payouts.final.private.json` необходимо исключить из ручного расчёта реальных выплат. Это не разрешение редактировать историю. Постоянное source-разделение сред требуется до использования отчёта как расчёта вознаграждения. Массовую платную кампанию следует оценивать после контрольной настоящей покупки, начисления и чека.

## Эксплуатация

При аварии после возможной live оплаты закрывать **новые** покупки флагом checkout, оставляя LIVE provider и canonical webhook для завершения и сверки. Не возвращать TEST ключи автоматически и не восстанавливать старую БД поверх новых операций. Боевой профиль/Compose и operator receipts находятся в закрытых файлах; в Git нет ключей, cookie, приватных ответов API или платёжных данных.

Автопродление — отдельная реализация optional-autorenew; его макет уже согласован владельцем, предкодовый QCSD продолжается. Сейчас списания выполняются только после ручного подтверждения покупки.
