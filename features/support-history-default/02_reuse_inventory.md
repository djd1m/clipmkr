# Переиспользование

- Серверный `widgetSession` подписывает 60-секундный JWT для действующей
  сессии активного пользователя с подтверждённой почтой. Внешний субъект —
  неизменный UUID Clipmkr. Сохраняются текущие аудитория, ключ и inbox.
- `loadSupportWidget` дожидается готовности canonical iframe, проверяет
  источник и origin и выполняет штатный logout до обращения со старой
  vendor cookie. Переиспользуются границы времени, скрытие, событие сброса
  и уничтожение устаревшего экземпляра.
- Libredesk v2.9.0 умеет загружать диалоги после JWT и открывать последний
  для `users.direct_to_conversation`. На рабочем inbox этот параметр сейчас
  выключен; настройку включить для подтверждённых пользователей при выпуске.
  [Исходный код навигации](https://github.com/abhinavxd/libredesk/blob/v2.9.0/frontend/apps/widget/src/App.vue).
- Сценарии браузера из `tests/browser/support-widget-readiness.test.ts`
  и `tests/browser/support-chat-closure.test.ts` уже моделируют запуск SDK,
  старые токены и закрытие. Синтетические обращения оператора используются
  отдельно для проверки установленной версии.
