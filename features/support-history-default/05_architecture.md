# Границы интеграции

```text
Поддержка Clipmkr → серверная сессия и UUID аккаунта → короткий JWT
                → штатный SDK → iframe Libredesk → существующие диалоги
```

- Авторитет входа — сервер Clipmkr. Токен остаётся короткоживущим и
  проверяется Libredesk. Контекст, медиа или заметки оператора в токен
  не добавляются.
- Перед открытием сверяются серверный субъект, эпоха виджета, ожидаемые
  origin и iframe. Неподтверждённая либо устаревшая попытка остаётся
  скрытой. Граница идентификации отлична от загрузки истории: статус
  «переписка готова» приложение самостоятельно не показывает.
- Штатные `setUser`, `logout`, `hide` и `destroy` владеют внутренней
  сессией и видимостью. После смены субъекта старый iframe выводится из
  обращения. При том же аккаунте закрытие не удаляет диалог.
- Настройку открытия последнего диалога подтверждённых пользователей
  применяет отдельный штатный интерфейс Libredesk. Версии web и Libredesk,
  исходное значение и результат сверяются после выпуска.
