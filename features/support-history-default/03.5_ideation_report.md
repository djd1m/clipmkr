# Проверка проекта поддержки

Три отдельные сессии GPT‑6 Astra xhigh проверили продуктовую пригодность,
границы доступа и минимальный набор проверок. На первом чтении выявлены
два риска: незавершённая попытка могла ответить после повтора, а вкладка B
могла прочитать общую cookie аккаунта A. Проект ограничен одной
неподтверждённой попыткой на iframe, штатным холодным входом через JWT,
межвкладочной инвалидацией и сохранением истории подтверждённых контактов.
Автоматическое слияние старого гостевого сеанса выключается на widget API.
Ревьюеры подтвердили изменения документов; `evaluate` закрыл оба условия
на ревизии `c73f3af4749622d0001c72fff99a5ba9cb85c7159f23cd6ffe348faa913c8be8`.
Проверок реализации на этом этапе не было.
