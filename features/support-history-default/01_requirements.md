# Своя переписка в поддержке

Владелец поручил выполнить текущий бэклог по порядку; это второй пункт.
Согласование конкретного [макета](../../docs/design/2026-11-18-support-and-player.md)
подтверждено. Ответ сохранён в `owner-authority.md`.

- FR-1. Вошедший подтверждённый пользователь видит одно начальное действие
   «Открыть чат поддержки» с кратким пояснением передачи почты Libredesk.
- FR-2. По нажатию открывается последний диалог; пользователь может продолжить
   обращение и перейти к остальным. Пустая история допускает первое обращение.
- FR-3. Закрытие возвращает к кнопке. Повтор в новом приватном контексте после
   входа открывает ту же историю по UUID пользователя.
- FR-4. Просроченный вход, ошибка сети или идентификации дают восстановление
   или повтор. При смене аккаунта прежняя история не запрашивается и не видна.
- FR-5. Сохранить почту поддержки, восстановление доступа и явное согласие на
   копирование технического контекста в дополнительных действиях.

Нормативная дельта [OpenSpec](../../openspec/changes/support-history-default/specs/support-history/spec.md),
SHA-256 `d8f52c6567598beea04a94d09d1a46ac99931640ccda4451101d0cea9e0015d1` на момент подготовки.
