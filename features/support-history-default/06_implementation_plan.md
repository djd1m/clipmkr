# План после согласования

1. Сверить согласованный макет, ADR и актуальную дельту OpenSpec.
2. Оставить одно видимое действие входа в чат. Подключить серверную подпись
   и подтверждение нативного виджета. Сохранить компактные состояния доступа
   и восстановление. Затронуты `SupportPanel`, `support-client` и привязка
   субъекта в `widgetSession` при необходимости.
3. На синтетических A/B и штатном Libredesk проверить возврат к ответу,
   холодный запуск, новый приватный контекст, смену аккаунта и поздний ответ.
   Проверяющий GPT‑6 Astra xhigh получит документы в новой сессии.
4. На текущем VPS выпустить проверенное приложение и настройку открытия
   диалога для подтверждённых пользователей. Зафиксировать исходный параметр
   для отката. Дать ссылку для ручной проверки.

До реализации нужны принятый макет и реальные контрольные точки feature-adr.
