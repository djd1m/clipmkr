# ADR-001. Подтверждённый чат по основной кнопке

## Decision

Сохранить текущий Libredesk, существующие контакты и вход персонала.
Идентифицировать по нажатию. Проверять субъект ответа API относительно
аккаунта, представленного на экране. При несоответствии забыть старое состояние
и предложить повтор после обновления страницы.

До подтверждения идентификации iframe скрыт. Слушатель ставится до
запуска SDK; успешный `STORE_SESSION` и последующий `WIDGET_LOADED`
привязываются к текущей попытке и canonical iframe. Сообщение от другой
вкладки, origin или заменённого iframe игнорируется. Начальное
`WIDGET_LOADED` и сигнал после отказа JWT сами по себе недостаточны.
Приложение не извлекает токен из сообщения и не записывает его.

На один iframe допускается одна неподтверждённая попытка. При тайм-ауте,
отказе, отмене или смене аккаунта скрипт скрывает виджет, вызывает штатный
сброс и выводит iframe из обращения вместе с его обработчиками. Повтор,
включая тот же UUID, использует свежий iframe. Уже подтверждённый iframe
можно повторно открыть после проверки текущего серверного субъекта.

Первая и последующие холодные загрузки получают JWT через штатное поле
`userJWT`, выставленное до запуска SDK. Работающий `widget.js` проверен:
`VUE_APP_READY` с `userJWT` отправляет `SET_JWT_TOKEN` и выходит до
чтения общей cookie сеанса. Поэтому B не использует позднюю запись
verified cookie из вкладки A. Штатный logout сохраняется при retirement.
Документация [Libredesk](https://support.libredesk.io/en/articles/livechat).

Ветка `userJWT` всё равно читает legacy visitor cookie. Установленная
версия может использовать её для слияния обращений с авторизованным
контактом. На маршрутах widget API выделенного хоста поддержки удалить
`X-Libredesk-Visitor-Token` при проксировании, сохранив основную
`Authorization` и остальные заголовки. Это прекращает автоматический
перенос старого гостевого обращения между аккаунтами через общий
браузер. Уже привязанные обращения и доступ сотрудника сохраняются.
Снимок конфигурации, отдельная проверка передачи заголовков и откат
входят в выпуск. [Код Libredesk v2.9.0](https://github.com/abhinavxd/libredesk/blob/v2.9.0/cmd/widget_middleware.go).

При изменении входа приложение отправляет непрозрачный маркер инвалидации
через оба доступных транспорта своего origin: `BroadcastChannel` и
`storage`. Подписчики принимают оба и игнорируют повторы одного маркера.
Получившая вкладка синхронно скрывает старый виджет, отменяет ожидание
и выводит iframe из обращения. Токены, UUID, почта и диалоги вовне
не передаются. Сигнал используется при входе, выходе и восстановлении
с заменой сессии. Проверка при возврате во вкладку остаётся дополнительной.
Если оба транспорта недоступны, показываем повтор или безопасный способ
связи вместо открытия персонального виджета.

Настройка Libredesk открывает последний диалог только для пользователей.
