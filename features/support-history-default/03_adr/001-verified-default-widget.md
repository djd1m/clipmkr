# Черновик ADR-001. Подтверждённый чат по основной кнопке

Сохранить текущий Libredesk, существующие контакты и вход персонала.
Идентифицировать по нажатию. Проверять субъект ответа API относительно
аккаунта, представленного на экране. При несоответствии забыть старое состояние
и предложить повтор после обновления страницы.

До подтверждения идентификации не показывать iframe. Нативные
`STORE_SESSION` и последующий `WIDGET_LOADED` после `setUser` служат
сигналами перехода; сообщение от другой вкладки, origin или заменённого
iframe игнорируется. Начальное `WIDGET_LOADED` и сигнал после отказа
JWT сами по себе недостаточны. Токен из сообщения не читается приложением,
не пишется в storage и не входит в логи. Точный порядок должен быть
подтверждён на установленной версии.

Сброс identity при смене аккаунта, выходе и возврате фокуса сохраняется.
Поздний ответ предыдущего iframe не открывает виджет. Для той же
подтверждённой сессии при повторном открытии допускается сохранить родной
экземпляр, если новое серверное обращение подтверждает того же субъекта.
Настройка Libredesk открывает последний диалог только для пользователей.
