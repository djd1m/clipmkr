# BILLING-001. Подтверждение почты перед покупкой

[Интерактивный макет](mockup.html) проверен в Chromium на ширине 390 и 1440 пикселей.
После скачивания HTML откройте его в браузере. Верхний селектор показывает восемь
состояний макета, переключатель темы использует текущую палитру кабинета.

- [Подтверждение из выбранного пакета на телефоне](mockup-checkout-390.png).
- [Возврат к выбранному пакету на десктопе](mockup-return-1440.png).

Пакет и цена остаются на экране. Письмо о подтверждении адреса использует существующую
процедуру Clipmkr. После перехода из письма пользователь подтверждает адрес в своём
аккаунте и явно нажимает кнопку оплаты. На экране результата покупки показаны
подготовка квитанции, принятие почтовым сервисом и состояние, требующее проверки.
Квитанция Clipmkr подтверждает покупку пакета. Фискальный чек ведёт ЮKassa.

17.11.2026 владелец поручил работу над BILLING-001. Владелец согласовал показанный макет. Точная ревизия и формулировка сохранены
в [решении владельца](owner-approval.md). Макет имитирует письмо, выбор состояния и оплату в браузере.
