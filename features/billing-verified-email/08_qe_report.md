- `node node_modules/vitest/vitest.mjs run --config vitest.browser.config.ts tests/browser/billing-verified-email-next.test.ts`.
  На `d339d20` прошли 4/4. Проверены выбранный пакет, прямой отказ неподтверждённому
  адресу, смена сессии в полёте, потеря ответа и повтор одного ключа, недействительная
  ссылка, ошибка письма, 320 CSS px и 200% текст. Собранный Next запустил
  настоящий watchdog и сохранил одну квитанцию через тестовый почтовый транспорт.

  приватности каталога и 1/1 по напоминаниям. Использованы Chromium
  148.0.7778.96 и WebKit 26.4 из Playwright 1.60.0.
- PostgreSQL подтвердил один платёж, одно начисление и одну квитанцию при
  реально перекрывающихся транзакциях. Принудительный отказ вставки квитанции
  откатил начисление. Обе мутации QT-1 дали ожидаемый RED.

  Для исторических строк создано ноль квитанций. Старое намерение без id
  осталось доступно для сверки.
- Отдельная диагностика на кандидате подтвердила запрет повторного письма
  после неизвестного исхода и возврата, а также запрет отправки при привязке
  чужого платежа с другой известной идентичностью магазина.
- Адресная партия `vitest run tests/payment-receipt-delivery.integration.test.ts tests/support-mail-resend.test.ts tests/support-email-handler.test.ts tests/support-ui.test.ts`.
