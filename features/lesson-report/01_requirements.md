# Требования к отчёту для занятия

Источник — прямые поручения владельца05.11.2026: интерактивный HTML по результатам
работы с прошлой пятницы, внесённые и планируемые изменения; занятие через40минут;
подготовить отдельным роем. Владелец отдельно подтвердил: **«Только Clipmkr»**.
Период:30октября–5ноября2026, недавние события5ноября включаются до фактической сборки.

- **FR-1. Доказанная история.** Показать содержательные изменения по датам/темам,
  проблему, действие, пользу и ссылки на проверенные документы/commit. Не считать
  число коммитов мерой результата; не включать выдуманные этапы/метрики.
- **FR-2. Честные статусы.** Различать внедрено, в работе, запланировано, заблокировано
  и остановлено. Согласованный макет не называть реализацией, локальные тесты —
  реальной оплатой, частичное QE — полной приёмкой. Отдельно показать ограничения.
- **FR-3. Интерактивность.** Фильтры по статусу/теме, поиск, раскрытие подробностей,
  хронология и следующие шаги. Режим показа для занятия с крупным текстом и понятной
  навигацией; основные сведения доступны и без выполнения сложных сценариев.
- **FR-4. Самостоятельный HTML.** Открывается в Chrome локальным файлом без сервера,
  npm, CDN и внешних запросов для работы. Данные/стили/скрипт внутри HTML. Ссылки
  на Git открываются только по явному действию. Предусмотрены печать и отсутствие
  горизонтальной прокрутки на390/1440, работа клавиатурой, пустой результат поиска.
- **FR-5. Безопасность публикации.** Документ по-русски, без паролей, токенов,
  пользовательских email/ID, приватных клипов, signed URLs и ненужных адресов серверов.
  Используются демонстрационные обозначения; нет платных/изменяющих приложение действий.
- **FR-6. Согласованность данных.** Канонический JSON и встроенный набор данных HTML
  совпадают. У каждого события указан источник и ограничения. Ключевые заявления
  самостоятельно сверяет отдельная модель, не написавшая HTML.
- **FR-7. Доставка.** Дать владельцу один скачиваемый HTML и краткую инструкцию
  открытия до занятия; маленькие проверенные commits/push во все3Git. Не требовать
  установки новой программы. Срок цели не трактуется как выполненная поставка.

За рамками: изменения Clipmkr UI/сервера, копирование БД, закрытие регистрации,
новые реальные E2E, платёжные операции и публикация на Cloud.ru. Упоминание этих
задач в отчёте не разрешает их исполнение. Прямой запрос интерактивного документа
разрешает его дизайн/создание; отдельное согласование продуктового UI к нему не относится.

План и факты ведутся в features/lesson-report; OpenSpec используется как требуемый
журнал дельты документа. Форматные проверки не заменяют браузер и независимую
проверку значимых статусов.
