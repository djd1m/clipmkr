# Экран целиком при первой нарезке Zoom

Task kind: bugfix

Предварительный уровень M для явно выбранного режима. Задействованы создание
записи, передача настройки в первую нарезку, композиция и проверка публикации.
Новый автоматический классификатор сцены потребуется оценить отдельно, если
владелец выберет этот способ включения. Кодовых дозволов на этом этапе нет.

На согласовании способ включения режима при первой нарезке. Опорный артефакт
видео — закрытый локальный предпросмотр на реальном примере. Материалы записи,
идентификаторы аккаунта и ключи хранилища в Git не помещаются.

Текущий этап M — ручная пересборка опубликованного клипа с переносом
камеры и исправленной проверкой конца фрагмента. Изменяются существующие
Canvas и FFmpeg, общий расчёт, проверка камеры и ограничение БД.
Первая нарезка и автоопределение демонстрации остаются отдельным этапом.
