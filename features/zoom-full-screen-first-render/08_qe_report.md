# Приёмка ручного переноса камеры

Образы web и worker-video собраны из Git-ревизии
`b113dc1a4bbcbbdbcdcaf0d8dc89a70828d9c0f9`. Против неё проверены
исходники приложения. После сборки изменился только браузерный тест:
он явно включает камеру, ждёт выбранную карточку и заранее подготавливает
React JSX runtime, чтобы Vite не перезагружал первое открытие.

Отдельное ожидание текста об окончании пересборки в уже открытом
редакторе не подтвердило этот статус. Готовность проверена по записи
публикации и по новой версии файла в браузере.

Независимый GPT‑6 Astra xhigh в отдельной сессии
`/root/camera_code_qe` закрыл пять исходных условий на снимке
`da0663a9365c18f2d3b189947b81caa67268e7115371bb13a3f69cec864de661`.
Штатный `check-review-convergence.mjs evaluate --phase qe` вернул
`closed`. Первоначальный локальный typecheck был остановлен старыми
артефактами зависимостей рабочей копии. Сборка из чистого Git-архива
выполнила штатный Next.js typecheck и собрала оба образа.

## Выкладка на clipmkr.ru

Рабочая БД сохранена через `pg_dump -Fc`, содержание архива проверено
`pg_restore --list`. Штатный `migrate` записал и подтвердил 035,
SHA-256 `92f299387ffd628180768959856cdb3664f42264835698557d46cf1d2c50e3d3`.
На VPS заменены worker-video, затем web. Остальные контейнеры проекта
сохранили свои идентификаторы. Публичный `/health` вернул `ok` и
точную Git-ревизию сборки.

Cloud.ru и DNS в этот этап не входили. Для ручной проверки владельца
нужно подтвердить новую пересборку в его клипе. После появления
опубликованных компоновок версии 3 предыдущие web/worker без поддержки 3
не являются совместимым откатом. Схема и резервная копия сохранены.

Проверка соответствия требований и кода выполнена для ручного сценария.
Автовыбор первой компоновки остаётся открытым этапом OpenSpec.
