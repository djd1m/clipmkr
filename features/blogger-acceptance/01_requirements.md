# Требования и переиспользование: кабинет блогера

Статус: требования владельца получены; архитектурный checkpoint нового M-плана ожидается.
Нормативная дельта: `openspec/changes/blogger-acceptance/specs/blogger-cabinet/spec.md`; SHA-256 `9f0a4f272eee0b60ffab557e8f18811b09db854873cd1a5a9d79ba06d5c4027a`.
Дополнительная общая приёмка: `docs/acceptance/core-cjm.md`.

| ID | Требование / проверяемый сценарий |
|---|---|
| FR-1 | Серверный лимит: обычный 5400 с, блогер 7200 с, индивидуальное значение только от владельца; граница включительна |
| FR-2 | Снимок лимита на video до расходов; последующие изменения профиля не меняют созданную запись |
| FR-3 | Владелец назначает блогера, лимит и необязательный процент 20/30; обычный пользователь и блогер не получают этот доступ |
| FR-4 | Своя реферальная ссылка и действующая статистика блогера сохраняются; владелец видит месячную сводку людей, использования и проверенных оплат по блогерам |
| FR-5 | Ставка не назначена — оценка отсутствует; назначена — целые копейки, пометка предварительного расчёта, никаких денежных переводов |
| FR-6 | Действующая оплата тарифа проверяется с настоящим магазином; без ключей результат интеграции явно BLOCKED, не PASS |
| C-1 | Миграция добавляющая; существующие квоты, кредиты, ключи, состояния очереди и записи пользователя не обходятся |

Переиспользуются native PartnerService, partner_code/attribution, payment/payment_intent,
owner-entitlement.hasOwnerUnlimited, operator_action, getProbeSource/acceptProbe, текущая
очередь и UI. Донор №6 — integer-арифметика процентов и независимые агрегаты; не его
коммерческие константы. Новый affiliate-сервис не нужен. Подробности: `docs/reuse/blogger-cabinet-projects-1-8.md`.

Риски: неверный доступ владельца, дублирование платежей в JOIN, подсчёт записей вместо людей,
расхождение лимитов между frontend/worker/DB/credit helpers, изменение уже принятого задания,
ложная приёмка оплаты с mode=off. Проверки указаны в ADR и плане. Оплата требует ответа о
магазине; точные будущие выплаты и база комиссии ещё не утверждены.
