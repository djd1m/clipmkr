# Требования к исследованию мобильного банковского UX

Дата: 05.11.2026. Источник — прямое делегированное поручение root в текущей исследовательской сессии. Владелец авторизовал исследование и отдельную команду; дополнительные продуктовые решения не запрашиваются и не объявляются принятыми.

## Участники и scope

Потребитель результата — владелец/команда Clipmkr; автор Sol high; независимый проверяющий — отдельная Astra xhigh после freeze, координирует root. Только Т‑Банк и Альфа‑Банк, публичные официальные мобильные evidence. Native Android, iOS и mobile web различаются. Никаких banking auth, APK, реальных счетов, правок UI/code/runtime/deploy/DB/credentials. Файлы разрешены только под `docs/research/mobile-banking-ux/` и этим feature scope; git mutations/commit/push — root.

## Исследовательские критерии

| ID / приоритет | Критерий приёмки документа |
|---|---|
| R1 MUST | По каждому банку разобраны8 сценариев; публичная инструкция не названа авторизованным проходом |
| R2 MUST | У каждого источника URL, дата наблюдения, тип, platform/version limits и observed/claimed; выборка bounded, максимум 30 |
| R3 MUST | 10–15 паттернов имеют problem→evidence→Clipmkr candidate→risk→test, confidence отдельно от transferability |
| R4 MUST | Три роли и все 21семейство текущего аудита покрыты компактной матрицей; MUST/worth testing/not applicable различаются |
| R5 MUST | Антипаттерны/superapp trade-offs и native↔responsive-web перенос объяснены; нет произвольных новых макетов |
| R6 MUST | Есть baseline→гипотеза→задача→критерий, честные NOT RUN и ограничения; UMUX/популярность не выдуманы |
| R7 MUST | Сохраняются утверждённый UI, core-CJM, runtime и OpenSpec; авторский self-check не объявлен независимым review |

При чтении каждого сравнения должен быть понятен статус: виден элемент / заявлена функция / наш кандидат / не установлено. Отсутствие публичного evidence не выдаётся за отсутствие функции. Декоративные изображения исключаются после визуальной проверки.
