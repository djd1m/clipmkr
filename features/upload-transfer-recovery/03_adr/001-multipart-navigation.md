# ADR-001: сохранить существующий multipart и защитить переход из формы

Status: superseded by ADR-002 и ADR-003; предложенная актуализация статуса 04.11.2026.
Историческое содержание решения ниже сохранено; оно не является разрешением нового кода.

## Context

Сервер не располагает File браузера. uploading в списке после refresh допускает переход
на страницу записи, а размонтирование формы отменяет PUT. Замена только ссылки ID не
устранила этот второй путь. Старый updated_at не свидетельствует о работе обработчика.

## Decision

Переиспользовать sessionStorage, прежний idempotency key и ListParts. Карточка uploading
не является ссылкой просмотра. В текущей форме обычный уход по ссылке подтверждается
штатным браузерным confirm, закрытие/перезагрузка — beforeunload. Отказ от ухода сохраняет
передачу; согласие отменяет её с сохранением восстановления. Успешный complete освобождает
защиту до автоматического router.push. При возврате форма объясняет повторный выбор файла.
Страница uploading объясняет незавершённую передачу независимо от давности updated_at.

## Alternatives and drivers

1. Только снять ссылку карточки: дешевле, но остальные ссылки оставляют потерю передачи.
2. Новая upload-библиотека/фоновый transport: большой перенос и нет доказанного выигрыша;
   сохранение File после закрытия браузера всё равно требует иной пользовательской модели.
3. Существующий multipart + штатная защита и восстановление: выбран, минимальный новый код.

## Consequences

Новая схема и зависимости не нужны. Native confirm имеет браузерный вид. beforeunload не
даёт гарантии для всех SPA history-переходов; возврат с тем же файлом проверяется отдельно.
Продолжение требует исходной вкладки/sessionStorage; потеря этих данных сообщается честно.

## Confirmation

C-1: обновлённый список с uploading не содержит ссылки просмотра; queued содержит.
C-2: отклонённый уход сохраняет PUT, подтверждённый позволяет уйти и затем восстановить
тот же ID/ключ без повторной отправки подтверждённой части.
C-3: uploading не получает текст о продолжающейся обработке; transcribing сохраняет
проверку давности. Мутации каждого свойства обязаны сделать соответствующий тест красным.


### Уточнение проверки, поступившее после решения 04.11.2026

tests/browser/upload-lifecycle.test.ts, tests/browser/video-screen.test.ts. Эта привязка
методов не утверждает фактический запуск. Старое «зависимости не нужны» заменено ADR-002;
границы pause/complete/guard уточнены ADR-003. Оригинал root-repo этим комплектом не изменён.
