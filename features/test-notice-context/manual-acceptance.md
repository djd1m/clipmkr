# Ручная проверка контекстных TEST-предупреждений

Изменение ограничено расположением предупреждений; это не протокол приёмки оплаты.

1. Откройте [clipmkr.ru](https://clipmkr.ru/) в отдельном окне инкогнито. Перед логотипом не должно быть строки «Тестовый стенд ЮKassa…». Нажмите «Войти»: форма доступна, финансовое предупреждение над страницей не появляется.
2. После входа откройте [Пакеты](https://clipmkr.ru/upgrade). В тестовой конфигурации рядом с каждой покупкой указано «TEST · Тестовая оплата. Реальных списаний нет». Нажимать покупку для проверки этого исправления не требуется.
3. Для блогера откройте [Статистику](https://clipmkr.ru/dashboard/partner); для владельца — [Блогеров](https://clipmkr.ru/dashboard/bloggers), затем отчёт. Здесь TEST-предупреждение должно пояснять, что выручка и расчёты учебные. Обычный пользователь по-прежнему не получает доступ владельца.
4. В обычном кабинете раскройте «Партнёрская программа»: TEST-пояснение должно появиться внутри этого раздела перед финансовыми показателями; при закрытом разделе лишней надписи в кабинете нет.
5. При желании повторите на узком экране, в светлой/тёмной теме и после обновления страницы. В [Аккаунте](https://clipmkr.ru/dashboard/account) прежний TEST badge сохранён.

Обычная конфигурация магазина и выключенная оплата проверяются локальной матрицей server JSX; рабочие переменные магазина ради этого исправления не переключаются. Cloud.ru не входит в поставку.
