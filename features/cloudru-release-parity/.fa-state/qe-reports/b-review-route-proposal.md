## Почему требуется решение владельца

Установленный feature-adr, шаг 8, устанавливает предел:
«Native QE keeps its default ceiling at three».
Единственное обычное продолжение разрешено только для третьего цикла,
«whose active cycle has never closed». Третий цикл A уже CLOSED; установленный
core явно возвращает `native-continuation-predecessor-closed` для такого случая.
Переименование feature/host/source или обнуление истории для нового B недопустимы.

Источники: [feature-adr SKILL.md](../../../../../node_modules/@dzhechkov/skills-feature-adr/templates/.claude/skills/feature-adr/SKILL.md),
[шаг 8](../../../../../node_modules/@dzhechkov/skills-feature-adr/templates/.claude/skills/feature-adr/modules/08-qe.md).
Это ограничения прочитанного skill/runtime; сами по себе они не являются
дефектом кода health и не превращают пройденный A в незавершённый native review.

## Предлагаемое исключение для согласованного оставшегося объёма

1. Владелец явно разрешает ручной cross-model маршрут для B и необходимых
   исправлений, найденных при оставшейся приёмке этого feature.
2. Код проверяют две не писавшие его модели: gpt-6-astra и gpt-6.1-sol,
   в новых сессиях без истории кодирования. Сначала согласованные документы,
   затем самостоятельная проверка реализации и тестов. Серьёзные новые находки
   исправляются и повторно проверяются другой моделью.
3. Для каждой проверки сохраняются точные source commit/файлы/hashes, модели,
   session IDs, собственные команды, результаты и ограничения. Тесты, K1 при
   новых именах, K2, literal coder context, проектные guards и anti-drift остаются.
4. Native история A остаётся историей A. Ручные заключения не выдаются за
   native cycle 4/CLOSED B; записи native/bridge не переписываются.
5. B доставляется только после независимого допуска и проходит настоящий
   A→B→A→B на обеих целях с сохранением старых и новых данных. Полный Cloud CJM,
   native TEST платежи и реферальные проверки также обязательны.
6. Production/DNS и реальные списания по-прежнему требуют отдельной команды
   владельца и не входят в это исключение.

До явного ответа владельца новый формальный QE по этому маршруту и доставка B
не начинаются. Проверки и пользовательская приёмка уже допущенного A продолжаются.
