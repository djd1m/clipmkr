эксплуатационных изменений и проверки сохранности выбран L. Активны этапы
0 → 1 → 2 → 3 → 3.5 → 4 → 5 → 6 → K1/K2 → 7 → 8 → 9.

Режим AQE: reference с расширенными протоколами; AQE MCP в текущем сеансе
не предоставлен. Direct runtime/fleet_init не объявляются выполненными.

Этапы и gates выполняются реально. Автономная подготовка разрешена владельцем;
