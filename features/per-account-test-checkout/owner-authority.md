## Применимость правила макетов

AGENTS.md требует макеты «перед реализацией изменений интерфейса». Здесь сохраняются
существующие каталог, цены, кнопки, TEST-индикатор и путь возврата; меняется только серверное
разрешение уже существующего действия для конкретного аккаунта по прямой просьбе владельца.
Поэтому новый макет для этого ограниченного изменения не требуется. Это обоснование границы,
а не выдуманное утверждение нового макета. Новый визуальный flow или новые настройки выйдут
за пределы этой задачи и потребуют отдельного согласования.

До кода обязательны независимый QCSD, K1/K2 и настоящие feature-adr checkpoints.
Факт поручения не является gate PASS. До применения private TEST overlay root проверяет
артефакт, синтетические отрицательные сценарии и границу testMode; live charges запрещены.
