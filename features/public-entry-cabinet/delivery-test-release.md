## Проверка владельцем в Chrome

1. Откройте https://clipmkr.ru в инкогнито: если уже выполнен вход, обычная вкладка может сразу открыть кабинет. На широком экране описание и пример слева, форма справа; на телефоне форма находится перед примером.
2. Нажмите «Войти» в шапке, затем «Начать бесплатно →»: режим должен стать «Создать аккаунт», фокус — в видимом поле почты. Переключите светлую/тёмную тему. Введённые значения должны сохраниться; код партнёра раскрывается только по желанию.
3. Для своего существующего аккаунта выберите «Войти», введите свою почту и пароль: должен открыться кабинет. Проверьте записи и клипы. Для новой регистрации используйте отдельную свою почту; ожидаемый пробный баланс —30кредитов/30минут.
4. Видеопримеры для просмотра: https://clipmkr.ru/c/CZPTEH и https://clipmkr.ru/c/5LL7LR . Это публичные страницы клипов; секретные подписанные ссылки не публикуются.
