# Состояния исходника — компактное дополнение для согласования

11.11.2026. Статус: синтетический HTML, **дополнительные состояния ещё не согласованы**. Нормальные «Смотреть/Скачать» из исходного опубликованного пакета владелец уже поручил реализовать; повторное согласование этого target не требуется.

[Открыть один интерактивный макет](../states.html). Выбор состояния и темы сверху предназначен только для демонстрации и не появится в приложении. Исходный `mockup.html` не изменён, SHA256 `ddfedb3cf797237955f044c22d5663cb07af8663771ed7c9cf03fc675484c174`.

| Состояние | Минимальное дополнение в существующем UI |
|---|---|
| Передача не завершена | Строка «Передача исходника не завершена», без source действий; выбранный клип остаётся. Существующее продолжение загрузки принадлежит нынешней progress panel, вторую кнопку не добавляем |
| Объект отсутствует / исходник недоступен | Строка «Исходный файл недоступен», без даты и обещания восстановления; клипы не скрываются |
| Проверка | Строка «Проверяем исходник…», без новых действий; viewer остаётся на выбранном клипе |
| Временная ошибка | Строка «Не удалось проверить исходник» и одна кнопка «Повторить»; нажатие показывает проверку. Не выдаём timeout за удаление |
| Неподдержанный браузером codec | Текст в прежнем viewer «Браузер не может воспроизвести исходник. Скачайте файл, чтобы открыть его в другом плеере»; «Скачать» остаётся в source row; «К клипам» возвращает выбор |
| Аудио | Та же строка с «Слушать · Скачать», в прежнем viewer native audio без пустого видеоэкрана; та же кнопка возврата |

Новых страниц, диалогов, меню, иконных тулбаров и кнопки refresh URL нет. Повторное открытие может получать актуальный доступ через прежнее «Смотреть/Слушать»; окончательное поведение expiry определит архитектор. Метаданные вымышлены; native audio содержит 1 с встроенной синтетической тишины, постер — встроенный SVG. Реальный исходник/подписанный URL/сеть не используются. Наличие native controls не является доказательством воспроизведения исходного codec.
