# Реестр источников и границы доказательства

Все источники проверялись **05.11.2026 UTC**. Ниже 17 содержательных первичных источников: 6 Т‑Банка, 8 Альфы, 3 по методике. [Индекс Alfa Digital](https://digital.alfabank.ru/digest) использован только для поиска нужных выпусков; CDN-assets относятся к своим публикациям, а не считаются независимыми подтверждениями. Поисковые результаты сторонних каталогов и «Альфа Гида» исключены из доказательств. Выборка ограничена формированием гипотез об иерархии и контекстных действиях; насыщение не измерялось. Пробелы в ошибках/доступности оставлены явными, а не заполнены дополнительными ссылками ради количества.

**V** — просмотрено изображение/кадры; **D** — прочитан официальный текст; **S** — доступен только текст через поисковый индекс, HTML недоступен. Любое утверждение банка об удобстве остаётся заявлением банка. Дата посещения не означает дату выпуска приложения. Если версия не опубликована в проверенном фрагменте, ниже стоит «не установлена».

## Визуальные свидетельства

Публичные банковские медиа не копируются в репозиторий. URL+SHA фиксируют именно просмотренный asset. Временные raw находятся у автора в `/tmp/clipmkr-mobile-banking-ux-research-20261105/raw/`; это временный cache, не постоянное хранилище проекта. После удаления cache повторная проверка идёт по URL, а несовпадение SHA означает новую ревизию, не автоматически подделку.

## Доступ и неудачные попытки

`web.search` возвращал содержательные официальные тексты; `web.open` для большинства банковских страниц возвращал502/timeout. Прямой Python urllib/requests с обычной проверкой TLS дал `CERTIFICATE_VERIFY_FAILED` (self-signed chain в этой среде). Только для **публичных read-only** материалов использован `requests.get(..., verify=False)`: T01–T06 и Alfa Digital вернули200; A01/A02 —403. Поэтому transport provenance ограничен: содержимое HTTPS не проверено стандартной цепочкой доверия в этом fallback. Никаких учётных данных или записей через него не отправлялось.

Три первых выбранных Alfa PNG оказались декоративными листьями/билетами, а не UI. Они были визуально просмотрены и исключены. Настоящее mobile свидетельство получено из linked official видео. Поисковые snippets не выдаются за просмотр HTML или авторизованного приложения. Playwright/полные native проходы/измерение task success — NOT RUN.
