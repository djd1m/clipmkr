# UI/UX для улучшения UMUX-Lite в Clipmkr

Исследование от 05.11.2026. Выбор OSS-библиотеки не гарантирует максимальный UMUX-Lite: это оценка воспринимаемой полезности и простоты **реальными пользователями после работы с продуктом**. Ни stars, ни AI-аудит, ни synthetic responses не являются таким измерением. Raw UMUX-Lite и SUS-регрессионная оценка имеют разные диапазоны; детали — в [плане измерения](measurement-plan.md).

Практическое решение для следующего согласованного дизайн-прохода: **существующие компоненты/CSS Clipmkr → Impeccable для критики сценариев → точечные Radix primitives при недостающем поведении → уже используемый axe/Playwright для проверки → два вопроса людям**. Это предложение; установка и продуктовые изменения не выполнялись. shadcn/ui — запасной источник согласованных React-блоков, SurveyJS — возможная форма опроса, Formbricks — отдельная исследовательская система при регулярной потребности, а не обязательный новый backend.

| Кандидат | Происхождение | Решение |
|---|---|---|
| Impeccable | Подтверждён в [aicoding.space, 30.10.2026](https://aicoding.space/blog/github-ai-llm-2026-10-30/#repo-pbakaus-impeccable) | Первый дизайн-аудитор рядом с native UI; его оценки не UMUX-Lite |
| Radix Primitives | Дополнительный аналог | Выборочно для focus/dialog/select; визуальный стиль остаётся нашим |
| shadcn/ui | Дополнительный аналог | Блоки и исходники, если оправданы Tailwind/tooling и стоимость сопровождения; не миграция всего кабинета |
| axe-core | Дополнительный аналог; Playwright adapter уже в проекте | Найти автоматизируемые a11y-дефекты; ручная доступность и usability отдельно |
| SurveyJS Form Library | Дополнительный аналог | Два rating-вопроса и export ответов; не автоматическая валидация методики |
| Formbricks | Дополнительный аналог | Опросы/учёт ответов для регулярного исследования; смешанные лицензии и отдельная эксплуатация |

Тренды подтверждены через официальный machine layer и точный passage, а не по общей популярности. Для остальных пяти membership в изученных GitHub-выпусках aicoding.space не установлен; упоминание shadcn в курсе не равно попаданию в тренды. [Карточки](project-cards.md) содержат реальные лицензии и срез активности; [источники](sources.md) отделяют наблюдение от вывода.

[Предыдущее OSS-дизайн-исследование](https://github.com/djd1m/clipmkr/blob/24b4b4a/docs/design/2026-11-04-oss-design-research.md) уже рекомендовало Impeccable и native reuse. Оно прочитано из Git commit, но не доказывает установку этих OSS в Clipmkr. Текущее направление владельца сохраняется: нейтральный зелёный, две темы, кабинет по умолчанию, studio — опция; обязательные действия видны, дополнительные настройки раскрываются по желанию. Новые макеты требуют прежнего согласования.

Высокий субъективный балл полезен только вместе с работающим CJM: загрузка → клипы/просмотр/скачивание, TEST-оплата, личная ссылка и правильная статистика. Доступность, скорость, функциональная корректность и UMUX-Lite — связанные, но разные результаты. Пилот здесь только спланирован, оценки Clipmkr не получены.
