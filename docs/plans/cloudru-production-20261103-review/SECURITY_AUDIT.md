# Проверка публикации документов

03.11.2026. Репозиторий GitHub проверен через API: публичный.

## Область и результаты

Проверены девять файлов коммита9bb7475,2840 текущих отслеживаемых текстовых файлов,
а также патчи истории документации/feature/Cloud.ru ops. Проверялись шаблоны приватных
ключей, токенов, подписанных URL, URL с паролями и точные совпадения со значениями
из существующих локальных настроек, профиля Hub, настроек тестовой оплаты и тестовых аккаунтов.
Значения для сравнения обрабатывались только в памяти и в отчёт не включены.
В этой области паролей, ключей, токенов и подписанных ссылок не обнаружено.
Это ограниченный аудит, не математическая гарантия отсутствия любых секретов во всех
бинарных файлах, исходниках или невыбранной истории репозитория.

В новых документах присутствовали конкретные IP, UUID ВМ/диска и имена инфраструктурных
ресурсов. Это не учётные данные, но такие сведения могут считаться чувствительными.
Их заменили условными обозначениями. Полная рабочая версия и соответствия сохранены
в закрытом операторском архиве вне Git: каталог0700,файлы0600.

Публичная версия плана теперь отличается от полной проверенной версии только редакцией
инфраструктурных обозначений и пояснениями публикации. SHA из исходных reviewer-отчётов
сохранён и относится к версии до редактирования. Новый SHA указан в README; повторное
независимое ревью после обезличивания не заявляется.

## История и ограничения

Исправляющий коммит не удаляет прежние версии из Git history, кэшей или уже сделанных копий.
Такие технические сведения также найдены в10 прежних отслеживаемых файлах за пределами
нового плана; этот ограниченный фикс не выдаётся за обезличивание всего репозитория.
История не переписывалась, доступность GitHub и действующие ключи не менялись.
Если потребуется полное удаление из истории, это отдельная согласованная операция;
в случае обнаружения действительного секрета одной чистки истории недостаточно — нужна ротация.
