# Последовательность поставки Clipmkr

Владелец попросил выпустить пять пунктов по порядку с приоритетом
быстрой и качественной реализации. Рабочий каталог — `/home/clipmkr`,
площадка выпуска — текущий VPS clipmkr.ru. Согласование макета относится
к изменениям интерфейса. Проверки подбираются к риску и текущей ревизии.

| Порядок | Результат | Состояние |
| --- | --- | --- |
| 1 | Автокомпоновка демонстрации в первой версии клипа с сохранением экрана | Выпущено. [Отчёт](../../features/zoom-first-render-auto/08_qe_report.md). |
| 2 | Одна кнопка для своей переписки, включая новый приватный контекст после входа | Выпущено. [Отчёт](../../features/support-history-default/08_qe_report.md). |
| 3 | «На весь экран» рядом с готовым клипом в кабинете и там, где гостю уже доступен плеер | Выпущено. [Отчёт](../../features/mobile-clip-fullscreen/08_qe_report.md). |
| 4 | Смена музыки готового клипа при частичном результате | Выпущено. [Отчёт](../../features/music-ready-while-rendering/08_qe_report.md). |
| 5 | Видимый список планов и отправка предложения из кабинета | Макет согласован. Закрытый приём через Libredesk и ручная публикация утверждённых карточек. [Требования бэклога](../BACKLOG.md#feedback-001--открытый-бэклог-и-прямой-запрос-новой-функции). |

Функции реализуются через feature-adr, закреплённый dz и OpenSpec.
Автор ведёт требования, код и поставку. Независимый GPT‑6 Astra xhigh в
новой сессии сверяет изменённый контракт и продуктовый сценарий по
согласованной ревизии. Для поддержки проверяются собственный диалог и
смена аккаунта. Для плеера — вход и выход с текущей позиции. Для музыки —
готовый клип, хвост обработки и сохранность предыдущего файла. Для
публичного списка — отправка предложения и ручная модерация. Общий
повтор прогонов применяется только при расширении затронутой области.
