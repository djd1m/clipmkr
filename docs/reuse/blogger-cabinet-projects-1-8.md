# Переиспользование кабинета блогера: проекты 1–8

Проверка исходников 2 ноября 2026, монорепозиторий `/home/2026-AUG-PU-Projects`,
наблюдаемый HEAD `b54ae24a7ca5227813886d98e20ea46735a3b6c9`.
Это внутренние проекты владельца, не отдельные публичные OSS-продукты.

| Проект | Найденные блоки | Применимость к Clipmkr |
|---|---|---|
| №1 Proofwall | partner.ts, n3-referral.ts, партнёрский кабинет и ставка | Полезен для сравнения, но отдельные dashboard tokens вместо текущей сессии Clipmkr |
| №2 ReviewQR | 004_billing_partners.sql | Основа оплаты/партнёров; для текущего Next/TypeScript кабинета менее прямой донор |
| №3 Affiliate Rewardful | referral-attribution.mjs, referral-payment и браузерные E2E | Самый полный отдельный affiliate-продукт; интеграция целиком добавляет второй контур |
| №3a | typed onboarding, роли и partner-assets | Полезен для приглашений; это не готовая финансовая сводка Clipmkr |
| №4 Тарелка | domain/commission.ts, partner-attribution, admin-partners | Исходный донор комиссий, уже адаптирован в №6 |
| №5 Clipmkr | PartnerService, PartnerPanel, свои ссылки, атрибуция, проверенные оплаты | Основная готовая база; сначала использовать её |
| №6 Суфлёр | packages/rag/src/commission.ts; packages/db/src/commission.ts и partners.ts | Предпочтительный точечный донор: TypeScript/Next/PostgreSQL, integer-арифметика, корректные агрегаты, тесты |
| №7 Warmup | Прямой готовый affiliate-модуль в просмотренных путях не обнаружен | Не выбран; это результат ограниченного поиска, не полный аудит |
| №8 Интерьер | В просмотренном приложении нет подходящего блока комиссий | Не выбран |

Решение после уточнения владельца: сохранить native авторизацию и кабинет №5; для недостающей реферальной сводки сначала использовать специализированный №3, а №6 — дополнительный донор арифметики. В новом blogger-report.ts адаптированы независимые агрегаты и уникальные плательщики из №3 shared/referrals/metrics.mjs; целочисленное округление — из №6. UI №3 mountReferralPanel использует DOM и отдельное membership/API, поэтому переносится смысл метрик и сценариев, а действующий React-интерфейс Clipmkr сохраняется. Не переносить
другую авторизацию, целый affiliate-сервис или коммерческие правила №6 (12 месяцев,
30 дней удержания, минимум выплаты, календарь). Эти правила владелец для Clipmkr не задавал.
Ставка 20/30 сохраняется явно, без неявного выбора; предварительная оценка не является
начисленной задолженностью. База предварительной оценки согласована: подтверждённая выручка пакетов за месяц.
Условия настоящих денежных выплат требуют отдельного решения.
