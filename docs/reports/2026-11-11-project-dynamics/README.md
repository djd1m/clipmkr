# Clipmkr — динамика за 5–11 ноября 2026 года

Повторный отчёт для занятия: что изменилось после прошлого четверга, чем завершились
прежние планы и что остаётся сделать. Все материалы на русском языке.

## Открыть отчёт

[Скачать интерактивный HTML](https://github.com/djd1m/clipmkr/raw/refs/heads/main/docs/reports/2026-11-11-project-dynamics/index.html)
и открыть сохранённый файл в Chrome. GitHub показывает исходник HTML, поэтому
для показа нужен именно скачанный `index.html`, а не сохранённая страница GitHub.
Сервер, npm, установка программ и подключение к сети для работы отчёта не нужны.

- **«Режим показа»** — слайды, кнопки и стрелки ←/→; Escape закрывает показ.
- **«CJM и макеты»** — заметный каталог прямых GitHub-ссылок и отдельный слайд.
  Для открытия самих внешних источников нужна сеть.
- **Хронология** — совместные фильтры статуса/темы, поиск, сброс и раскрытие источников.
- **«Печать»** — полный отчёт со всеми событиями и источниками, даже если часть
  событий скрыта фильтрами; можно сохранить в PDF.
