# Промпт еженедельного отчёта Clipmkr

Подготовь интерактивный отчёт для занятия о возможностях Clipmkr за 18–25 ноября 2026 года включительно, по образцу выпуска от 18 ноября. Используй даты UTC и зафиксируй время среза 25 ноября. Учитывай пересечение двух отчётов 18 ноября. Указывай сначала действие, которое изменилось для человека, затем причину, проверку, результат и предел доказательства.

Сверь Git и проектные протоколы. Для существенных событий укажи ссылку на точный публичный коммит и файл. Различай выпущенные изменения, видео с записью действий, изменения лицензии и документации, аудит, макеты на согласовании и отклонённые предложения. Для видеотура покажи семь переснятых эпизодов с видимым курсором и ссылками на просмотр. Описывай оценку регрессии, ручную приёмку и ограничения с привязкой к версии и среде.

Переиспользуй автономную страницу предыдущего отчёта. Сохрани поиск, фильтры по статусу и теме, раскрываемые источники, раздел «CJM и макеты», презентацию с управлением стрелками и Escape и печать полной хронологии. Сделай текст отчёта, данные JSON и отдельный список доказательств. Проверь точность встроенных данных, ссылки, работу без сети, доступность управления и отсутствие горизонтальной прокрутки на ширине 390 и 1440 пикселей.

Опубликуй проверенный HTML в отдельной папке GitHub Pages. Работай с опубликованными документами и артефактами. Операции с приложением, пользовательскими данными и оплатой выходят за границы отчёта.
