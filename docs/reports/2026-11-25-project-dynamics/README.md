# Clipmkr за 18–25 ноября 2026 года

Отчёт для занятия охватывает Clipmkr с 18 ноября до времени среза 25 ноября по UTC. Часть событий 18 ноября также разобрана в предыдущем выпуске. Ревизии и границы проверки указаны в карточках и сводке доказательств.

## Открыть

- [Интерактивный отчёт на GitHub Pages](https://djd1m.github.io/clipmkr/2026-11-18-25/).
- [Автономный HTML](index.html) можно скачать через **Download raw file** и открыть в браузере без сети. Сеть нужна для перехода к источникам и видеотуру.

В **«Режиме показа»** стрелки переключают слайды, а Escape закрывает презентацию. В хронологии работают поиск и фильтры. **«CJM и макеты»** ведёт к пользовательским сценариям, статусам макетов и семи демонстрациям с курсором. **«Печать»** включает всю хронологию и раскрывает источники.
