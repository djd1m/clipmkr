# Ручная проверка тестового Clipmkr на Cloud.ru

4 ноября 2026. Опубликованный стенд: **https://c.clipmkr.ru**.
Основной домен не переключён. Полная автоматическая приёмка Cloud CJM ещё идёт;
наличие страниц не означает завершение всех проверок.

Для владельца подготовлены три отдельные учётные записи ручной приёмки:
пользователь, блогер и владелец. Каждая зарегистрирована через опубликованный UI;
повторный вход с паролем в новом браузерном контексте проверен. Право владельца
назначено существующей операторской командой с аудитом, блогер — через owner UI.
Данные входа находятся в отдельном закрытом файле оператора вне Git. Здесь паролей,
сессий, адресов аккаунтов и подписанных медиа-ссылок нет.

| Сценарий | Адрес и действия |
|---|---|
| Вход | https://c.clipmkr.ru/#auth; отдельный профиль браузера для каждой роли |
| Пользователь: загрузка и результат | https://c.clipmkr.ru/dashboard; выбрать файл от 2 до 90 минут, дождаться записи, Play и «Скачать клип» |
| Блогер: загрузка и результат | Тот же dashboard под блогером; стандартный предел — 120 минут |
| Покупки | https://c.clipmkr.ru/upgrade; Старт, Про и дополнительный пакет; подтверждение пакета после уведомления магазина |
| Своя реферальная ссылка | Dashboard блогера; создать ссылку, открыть её в новом приватном окне и зарегистрировать новый аккаунт |
| Статистика блогера | Dashboard блогера; проверить переходы, регистрации, использование и подтверждённые покупки |
| Управление и сводка владельца | https://c.clipmkr.ru/dashboard/bloggers; найти ручного блогера, изменить индивидуальный лимит и ставку, проверить сводку |

У ручного блогера назначены стандартные 120 минут и ставка 20%; собственная
ссылка создана через UI. Покупки, нарезки и привлечённые регистрации для этих
аккаунтов не имитировались. Уже зарегистрированный напрямую пользователь не
становится привлечённым после открытия ссылки: для этого нужен новый аккаунт.
Пустое индивидуальное значение возвращает блогеру стандартные 120 минут.
Оценка 20/30% — расчёт по подтверждённой выручке выбранного месяца с исключением
возвратов; это не автоматическая выплата.

## Условия параллельной ручной проверки

Оплата Cloud проверяется настоящим тестовым магазином ЮKassa в согласованном
временном окне. После его закрытия checkout временно выключается до завершения
возврата callback; это не включение реальных списаний. В момент подготовки
доступа автоматический блогер уже получил пакет Про через native notification.
Этот результат относится к отдельному аккаунту автотеста, а не к ручным аккаунтам.

Ручные аккаунты получают штатные стартовые кредиты; оплаченные права специально
не выдавались. Для первого прохода удобна небольшая запись от двух минут.
Соблюдение максимальной длительности не отменяет проверку баланса и суточных квот.
Обработка использует настоящих поставщиков и общие ресурсы тестового стенда;
дополнительная задача может ждать автоматический длинный прогон в очереди.
Для изменения условий использовать только выделенные ручные аккаунты.

Четыре клипа предыдущего n5-прогона повторно воспроизведены в отдельном Chromium
без входа: время воспроизведения больше секунды, декодированные кадры есть,
ошибки media отсутствуют. Временные ссылки переданы владельцу отдельно и в Git
не хранятся. Эти клипы не выдаются за результат текущего Cloud-прогона.
