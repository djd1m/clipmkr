# Публикация планов Clipmkr

Пользователь открывает «Планы Clipmkr» из экрана аккаунта и может отправить
идею в существующем чате. Ответ и дальнейшие уточнения остаются в том же
диалоге. В Libredesk оператор может пометить тему тегом предложения и
объединить повторы при разборе.

Для публичной карточки обновить [подборку](../../apps/web/src/app/roadmap/public-roadmap.ts):

1. Выбрать короткий стабильный ID, название и описание публичным языком.
2. Выбрать статус `planned`, `in-progress` или `done`. Использовать
   `done` после выпуска на clipmkr.ru.
3. Сверить карточку с исходным продуктовым решением, сделать обычный
   коммит и выпустить его в текущем порядке проекта.
4. Открыть [планы Clipmkr](https://clipmkr.ru/roadmap) без входа
   и проверить конечный текст и статус.

Публикуемые поля набираются отдельно. Переписка, данные аккаунта, ссылки
на приватные записи и вложения из входящих обращений в подборку не входят.
