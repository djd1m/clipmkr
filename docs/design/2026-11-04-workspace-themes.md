## Как проверить

Скачайте HTML из GitHub через Download raw file и откройте в Chrome.
Переключите тему, последовательно выберите три экрана и перезагрузите файл.
Для клавиатуры: перейдите к переключателю через Tab и нажмите пробел.
В макете выбранный демо-файл сохраняется при смене темы; файл не читается и не передаётся.
Кнопки просмотра и оплаты открывают только пояснения, постеры содержат вымышленные данные.

В приложении переиспользуется существующий `ThemeToggle` с cookie `n5_theme`
и серверной установкой темы. localStorage в этом HTML относится только к прототипу.
Код приложения и выкладка на Cloud.ru этой правкой не менялись.

## Проверка этой ревизии

- Автор изменения: запрошенная `gpt-6.1-sol`, рассуждение `high`, изолированный worktree.
- Независимое ревью: запрошенная `gpt-6-astra`, рассуждение `xhigh`, новая read-only
  сессия `01a1a638-a111-7ce2-a7ec-57c80a5b284f`; вердикт **READY-TO-PRESENT**.
  На входе — AGENTS.md, матрица моделей, решение владельца, затем самостоятельное чтение HTML.
  Контекст кодирования и прежние отчёты не передавались.
- Браузерная проверка координатором: Chromium и WebKit, Node 22.23.4, Playwright 1.60.0,
  контейнер без сети. **108 комбинаций вёрстки**: шесть ширин × три экрана ×
  A / B светлый / B тёмный × два движка. Переполнения и перекрытия выбора файла не обнаружены.
- **12 прогонов axe color-contrast** — выявленных нарушений нет. Это проверка конкретного
  правила, не сертификация полной доступности по WCAG.
- **4 клавиатурные проверки**: пробел меняет тему, фокус остаётся на переключателе и виден
  в обеих палитрах, в обоих движках.
- Проверены сохранение светлой/тёмной темы после перезагрузки, сохранность выбора демо-файла,
  работа переключателя при недоступном localStorage и три демо-кнопки пакетов.
  Ошибок страницы и внешних запросов — 0.
- Отдельно прошли **30 существующих тестов** механизма тем приложения.

Ширины: 320, 390, 672, 768, 1024, 1440 px. Независимое ревью было статическим;
браузерные проверки выполнены отдельно. Указаны запрошенные модели и effort:
самостоятельная аттестация фактического runtime недоступна.
