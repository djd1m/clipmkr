# Clipmkr · поддержка и полноэкранный просмотр

Макет доступен для согласования. [Интерактивный HTML](2026-11-18-support-and-player.html)
можно скачать через Download raw file и открыть в браузере. Переключатели в верхней
части макета показывают состояния и две существующие темы Clipmkr.

## 2. Поддержка

- [Одна кнопка для вошедшего пользователя](screenshots/support-history-entry-390.png).
  Под кнопкой отдельного согласия больше нет. Перед нажатием видна цель передачи
  почты. Страница не создаёт сеанс Libredesk при одном лишь посещении.
- [Открытая переписка](screenshots/support-history-open-390.png).
  Состояние иллюстративное. Переписку, вкладки и её действия отображает штатный
  виджет. Для вошедших с историей используем его штатную настройку открытия
  последнего диалога. Посетитель без переписки может начать разговор.
- Гость видит вход и восстановление. Вошедший с неподтверждённой почтой получает
  ссылку на подтверждение. Технический контекст и почта поддержки доступны
  в раскрываемом разделе.
- При временном сбое на странице остаётся повтор действия. Чат показывает
  историю только после подтверждения сеанса текущего аккаунта.

Для реализации используем текущий серверный JWT и проверенный идентификатор
аккаунта. У Libredesk v2.9.0 есть настройка `users.direct_to_conversation`.
Её текущее значение проверено через настройки работающего inbox и равно
`false`. Переписка и роли сотрудников остаются в Libredesk.
[Официальная документация виджета](https://support.libredesk.io/en/articles/livechat) ·
[Исходный код навигации Libredesk v2.9.0](https://github.com/abhinavxd/libredesk/blob/v2.9.0/frontend/apps/widget/src/App.vue).

## 3. Полноэкранный просмотр

- [Кнопка под готовым клипом](screenshots/player-fullscreen-entry-390.png).
  Действие размещено рядом с самим видео перед скачиванием. Подпись и порядок
  одинаковы в кабинете и на отдельной публичной странице клипа.
- [Открытый просмотр](screenshots/player-fullscreen-open-390.png).
  Предпочитаем нативный полноэкранный режим видео. Этот снимок также показывает
  доступный резервный вариант внутри страницы с видимым закрытием.
- Позиция и состояние плеера сохраняются при входе и выходе. У готового клипа
  используются текущие файл и плеер. На недоступном клипе действия нет.
