# Автоматическая ссылка блогера — макет для согласования

Блогер входит в кабинет и получает готовый адрес. Придумывать код и нажимать
«Создать ссылку» не нужно: остаётся **«Копировать ссылку»** и отправка подписчикам.

Новый компактный блок расположен рядом с привычной загрузкой: справа на компьютере,
после действий загрузки на телефоне. «Новая запись», выбранный файл и «Создать клипы»
сохраняют существующую композицию. Обе темы и «Монтажная» доступны в настройках макета.

В верхней панели можно посмотреть загрузку, ошибку с повтором и блокировку.
Заблокированная ссылка сохраняется; новый код для обхода блокировки не предлагается.
Все данные, файл и URL в прототипе демонстрационные. Загрузка и генерация не запускаются.

Ссылка будет принадлежать самому блогеру. Существующий серверный генератор уже есть;
для реализации нужны сохранение прежних кодов и серверная проверка прав/антифрода.
Владелец назначает роль, блогер входит в собственный аккаунт.

Сейчас подготовлен только макет. Следующий шаг — согласование этого расположения и
действий владельцем, затем feature-adr и реализация с проверками. Новый UI не развёрнут.
