# Публичные планы и предложения Clipmkr

[Интерактивный макет](2026-11-18-public-feedback.html).
Открыть скачанный HTML или посмотреть снимки
[планов](screenshots/public-feedback-roadmap-390.png) и
[входа в чат](screenshots/public-feedback-proposal-390.png).
Названия карточек показывают структуру страницы.

В кабинете рядом с поддержкой появляется ссылка «Планы Clipmkr».
Публичная страница открывается без входа. Пользователь видит статусы
и может отправить предложение из кабинета через уже работающий чат
Libredesk. Вошедший пользователь открывает свою переписку подтверждённым
аккаунтом, до входа сохраняются обычные вход и восстановление.

Команда разбирает предложения в существующей очереди поддержки и может
уточнить детали в том же диалоге. Пользователь видит ответ при повторном
открытии чата. Владелец вручную публикует обезличенное описание и
статус подходящей задачи. Публичные карточки ведутся отдельно от обращений.
