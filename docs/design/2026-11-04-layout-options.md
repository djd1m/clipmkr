## Как проверить

Скачайте HTML через Download raw file в GitHub и откройте в Chrome.
Раскройте «Настройки», смените компоновку и тему, затем перезагрузите файл.
Проверьте возврат в «Кабинет»; выбор темы при этом сохраняется.
Служебный селектор «Экран» позволяет посмотреть загрузку, результат и пакеты.

Выберите демо-файл, смените компоновку и вернитесь: выбор остаётся общим.
На результате выберите второй клип в «Кабинете», перейдите в «Монтажную» и обратно:
выбранный клип сохраняется. Клавиатура: Tab к «Настройкам», Enter открывает их;
пробел на переключателе темы меняет палитру и сохраняет видимый фокус.

Все данные вымышлены; настоящие загрузка, воспроизведение, скачивание и оплата
не выполняются. Прототип хранит только предпочтения вида в localStorage.
Для приложения сохранность активного загрузчика и серверных операций проверяется
отдельным UI E2E после реализации через feature-adr/OpenSpec и настоящие K1/K2.
