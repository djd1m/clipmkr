# Clipmkr · статус пересборки оформления

[Интерактивный макет](2026-11-18-clip-layout-status.html). На GitHub нажмите **Download raw file** и откройте HTML в браузере. Переключатели над карточкой позволяют сравнить состояния и обе темы. Они относятся к макету.

## Карточка клипа

Короткая строка находится под названием того клипа, который обновляется. Она видна при свёрнутом редакторе и на мобильном экране. Плеер и скачивание прежней версии доступны, пока файл действует.

| Состояние | Что видит пользователь |
| --- | --- |
| Обычный просмотр | Заголовок и плеер. Строка статуса скрыта. |
| Пересборка принята | Маленький спиннер и «Обновляем оформление…». Ожидание воркера и рендер используют одну подпись. |
| Новая версия опубликована | «Оформление обновлено» с отметкой готовности. Строка исчезает через несколько секунд. |
| Пересборка завершилась ошибкой | «Не удалось обновить оформление» и действие «Открыть редактор». Последняя доступная версия остаётся в плеере. |

Выбор варианта и предпросмотр сами по себе не включают индикатор. В продукте состояние показывает результат серверного запроса. Кратковременный успех начинается после публикации обновлённого файла.

## Приёмка макета

Проверить, что статус читается с первого взгляда, виден после закрытия редактора, относится к одному клипу и отличим в обеих темах. Подтверждение макета определяет расположение строки, подписи и действие при сбое.

Проверены офлайн-переключения состояний и тем на 320, 390 и 1440 px.
Независимый `gpt-6-astra xhigh` проверил работу плеера, свёрнутый редактор,
клавиатурный путь, краткий показ успеха и отсутствие статуса у соседнего
клипа. После обнаруженного переполнения проверены экран, редактор и диалог
на 320 px при тексте 200% в Chromium и WebKit.
